# 材料点と織込みの仕様

- 仕様版：材料点台帳・初版。
- 対象：NK225先物、TOPIX先物。日中07:45／夜間16:00に情報を締める。
- 目的：ニュースの整理結果を、影響・既反映・残余へ分解して表示する。材料点を使っていない状態を、ニュース分析済みとして扱わない。
- 本仕様は新規実験用である。旧実験の予測、材料注釈、採点、学習原本は変更しない。
- 詳細定義と一次研究は[材料の織込み点](../../docs/材料の織込み点.md)を参照する。

## 固定する表示と計算

| 列 | 定義 |
| --- | --- |
| 材料 | 単一の経済事象。初報・転載・続報は同じ材料群にまとめる |
| 総影響T | −5から+5の主観pt。事前期待を控除する前の総作用 |
| P0までB0 | 事前期待による先行反映と、初報後から前セッション基準価格までの追加反応を重複なく含む主観pt |
| P0後D | P0から情報締切までの同先物の追加既反映pt。累計ではない |
| 既反映合計B | B0＋D |
| P0基準Q | T−B0。前セッション基準から先を説明する寄与 |
| 締切以後R | T−B0−D。Q＝D＋Rを確認する |

- 計算の手入力はT・B0・Dのみ。Q・Rを別々に捏造せず計算する。
- 点数は価格の指数ポイント、百分率、確率、真の織込み率ではない。
- B0・Dは総影響を超えたり逆符号になったりし得る。割合0〜1への制限や、首位確率の強制は行わない。
- 事前予想との差へ縮めた影響点に、期待済み分を再控除しない。旧 `novelty × (1−priced_in)` を新式へ重ねない。
- `null` は未識別。0は根拠を伴う中立・追加反応なしであり、欠測の置換に使わない。
- 当日を必須にし、1週間・1か月・3か月は期間別判断か未算出を明示する。当日点数の単純コピーで埋めない。

## 点数より先に固定する根拠

- 各記事版の初報・公表・取得・有効時計、ID、本文の出典と保存範囲。
- 当時の事前期待、実績、前回値、差、単位。存在しない予想は推測しない。
- P0の同先物価格、実観測時計、セッション、限月確認状態、正式終値の代理。
- P0前の同先物反応と、P0後から締切までの反応を別の時間窓へ分ける。
- 外部市場の反応は出典・時計・通貨方向・変化を別記し、閉場中の国内先物へ既反映したと自動換算しない。
- 各先物への利益・需要・割引率・為替・需給の伝達経路、反証、相殺する材料、失効条件、後続予定。
- 同じショックへの為替・海外株反応を独立の材料として重複加点しない。

P0当時の固定台帳と、締切時にP0までを再構成した台帳を区別する。後日の注釈を当時保存済みと表示しない。既知18回等の結果を既に見ている担当による点数は、回想・非盲検の開発注釈として保存する。

## 五分類への接続

- 点数合計の正負だけでは五分類を決めない。初動とその後の反転を、それぞれの材料・流動性・後続予定で説明する。
- 前ナイトの下落を翌日中の先行下落へ数えない。対象セッション内の順序で反転を予測する。
- 「もみ合い」は点数合計0と同義ではない。相殺する強い材料は大きな往復を生む可能性がある。
- 人間またはLLMの回答者、参照した材料ID、具体的なT・B0・D・Q・Rとの対応、反対条件を回答へ束縛する。
- 五分類の評価対象、初回到達、最初の反転、もみ合い優先は現行規約を維持する。
- 事前台帳と結果側の未知臨時材料認定を分ける。予測の当否に独立した認定で公表前を主評価にし、全場は参考として残す。予定指標・会見のサプライズは打切らない。

## 受け入れ条件

- 2先物の材料別T・B0・D・B・Q・Rと根拠が一覧で読める。
- 未来記事、未来観測、P0前後をまたぐ不適切な窓、重複材料、期限切れ材料を検知する。
- 点数が未知なら、その未知が合計へ伝播し、既知材料だけの小計を総合確定値と表示しない。
- 材料と点数を参照しない回答、総合点の符号だけの反転回答を受け付けない。
- 下記仮例で分母と符号が一致することを検証する。

| 仮例 | T | B0 | D | Q | R |
| --- | ---: | ---: | ---: | ---: | ---: |
| 既にナイトで反応済みの悪材料 | −4 | −3 | 0 | −1 | −1 |
| P0後に下落した材料 | −4 | −1 | −2 | −3 | −1 |
| 好期待に届かない実績 | +2 | +4 | 0 | −2 | −2 |
| 過反応の可能性 | −3 | −5 | 0 | +2 | +2 |
| 織込み未識別 | −3 | null | null | null | null |

これらは仕様確認用の仮例であり、実在ニュースの採点や予測精度の証拠ではない。実装の検査成功、材料分析を実施した証跡、未知期間における五分類の精度は別々に判定する。
