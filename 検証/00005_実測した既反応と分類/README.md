# 実測した既反応と方向分類

- 主観的な織込み率の積を外し、先物の既反応量を実測。方向分類を直接学習する３方式を比較した。
- 初期教師12場×２先物、評価18時点×２先物。いずれも全回発行、保留０。
- 予測固定→原結果開示→短い振り返り→次回学習の順に再生した。

- 判定：全方式80％未達。不採用。基準の直前追随は両先物9/18。
- 既知期間の開発再生。54回再生しても独立した市場時点は18件。
- 末尾窓は全18回で欠測あり。完全な60分変化とは表示せず、観測点間変化と足数を保持した。
- 市場観測は実数だけを取得。日付・前日値の欠損や不整合を推測で補わない。
- 正式引け値・当時の受信履歴・長期の未使用価格期間は引き続き不足している。
