# 実験計画

- 固定規約：同じ先物のP0、場中0.5％到達、五分類、もみ合い優先、未知の重大な臨時材料の公表前まで。
- 予測担当は場ごとに会話履歴なしで起動。未来の価格・記事・他場結果・集計を読ませない。
- 当回の順序：
  1. `次回` で最初の未完了場を確認。時点入力と反応台帳の当回用snapshotを渡す。
  2. 主導材料と展開・T/B0/D/Q/Rを判断し、`material_report` で回答と出典を固定。
  3. 別担当が予測・価格を読まず、当回の重大な臨時材料を認定。
  4. `開示` で初めて対象場の価格を読む。
  5. 同じ予測担当が外れ・当たり・不明を振り返り、`振返` で固定。
  6. `append_reaction_case` で反応事例を追加し、`反応固定` で結び付ける。次回へ進む。
- 更新内容：材料の新規性、事前期待、既反応、継続／反転、指数別伝達、反証、似た事例の限界。
- １例の結果を一般則にしない。因果未識別・臨時材料認定不明・欠測は明示する。
- 次回向けsnapshotも固定出典へ加える。後日の認定や未満了例を過去へ遡って渡さない。
- 集計：新35場と初期事例３場を分離。主評価と全場参考の正解下限・上限、分母、未確定、無回答を保存。
- 順序・ハッシュ検査の成功と予測精度の成功を分離。全場実行前に完成・80％達成と記さない。

## 補助コマンド

```powershell
python -X utf8 -c "import runpy;runpy.run_path('local/継続ブラインド/補助.py',run_name='__main__')" 次回
python -X utf8 -c "import runpy;runpy.run_path('local/継続ブラインド/補助.py',run_name='__main__')" コマンド --session 2026-09-23_Day
python -X utf8 -c "import runpy;runpy.run_path('local/継続ブラインド/補助.py',run_name='__main__')" 集計 --out local/継続ブラインド/最新集計.json
```

- `コマンド` は引数配列を返す。文字列をシェルへ無加工で連結せず、引数として実行する。
- `開示`・`振返` は `--session` を指定。`反応固定` は加えて `--case <不変の個別事例JSON>` を指定。
- 初期事例の結果は維持し、反応台帳だけへ追加する。旧予測を作り直して新35場へ混ぜない。
