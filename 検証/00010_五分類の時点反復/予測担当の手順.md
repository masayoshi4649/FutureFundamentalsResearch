# 当回の五分類予測

- 日本語UTF-8。読取許可は指定した当回 `masked/入力.json` とこの静的指示のみ。
- 他回・他レポート・原価格・原結果・ウェブ・追加ニュース・過去会話を読まない。内部知識で締切以後の情報を補わない。
- 当回締切までのニュース全文、実測した先物状態、市場実数、満了済み教師、自分の過去考察だけを使う。
- 初期教師の経路が未確定なら正解ラベルを捏造しない。候補集合を確率と呼ばない。
- 07:45は直前Nightの同じ先物終値代理→Day。16:00は当日Day→次Night。
- 現物前日比は採点基準にしない。前Nightの下落をそのまま当Dayの追加下落へ転記しない。
- 対象は場中に前終値から上か下へ0.5％以上到達する回。全予定回で先に回答し、後から対象回を選ばない。
- 回答は各先物一つ：`上がる`、`下がる`、`上がってから下がる`、`下がってから上がる`、`もみ合い`。
- `もみ合い`：対象場の高値安値の差÷前終値が１％以内、かつ終値の前終値比が絶対0.5％以内。境界を含む。反転していても、この条件を満たせばもみ合いを優先する。
- それ以外は、最初に前終値比±0.5％へ到達した方向を起点にする。その後の高値／安値から前終値比0.5％以上反転すれば折返し。終値で前終値を越える必要はない。
- 上へ先に到達して反転：`上がってから下がる`。下へ先に到達して反転：`下がってから上がる`。複数往復でも最初の起点を入れ替えない。
- 反転しなければ初回到達方向に従い`上がる`／`下がる`。もみ合いと終点±0.05％横ばいは異なる。
- 基準価格自体を場中高安へ算入しない。価格欠測や高安の順序不明を都合よく補間しない。
- 材料の新規性、直前先物で織り込んだ分、次場への追加反応、往復を起こし得る既知材料を分ける。
- 各先物で最も整合する一つの仮説を選ぶ。優位性は未検証。未校正の確率や％予測を作らない。
- 根拠IDは当回 `news` から重複なく３件以内。記事なしは空配列。
- 既反応・追加反応は各140字、反証は100字以内の一行。
- 書込許可は指定した当回 `予測入力.json` の新規保存のみ。予測結果はまだ開示されていない。
- JSON形式は次のとおり。追加キーと装飾は禁止。

```json
{
  "instruments": {
    "NK225": {
      "direction": "上がる",

      "additional_reaction": "次場の経路と、もみ合い優先条件を踏まえた仮説",
      "invalidation": "仮説が崩れる条件"
    },
```

- 保存後は２先物の回答だけ返して停止。結果開示後に同じ担当へ考察を依頼する。
- 考察時の読取許可は当回入力・この手順・固定予測・当回結果だけへ拡張。ほかの回は読まない。
- 考察は当回の値動きと仮説を比較し、原因は未識別／仮説と表示。原因不明を未知材料の発生と断定しない。
- 個別の次回対応を残す。正解でも反対材料と偶然の可能性を点検する。
