# 次回以降へ適用した更新

- 同じ場の予測は修正しない。変更は未発行の回から使い、実読資料とコードを発行時に固定する。
- 累積成績は更新を続ける研究手順の成績。同じ固定モデルの独立した将来勝率とは区別する。

| 採用回 | 更新 | 解消する問題 |
| --- | --- | --- |
| 初回から | 本文を別担当が表示前に切出し、新しい反応台帳を開始 | 全文を読んだ後の除外では未来情報を忘れられない |
| ４場目から | 公式の祝日取引・現物休場の条件を別入力 | 現物の反応を見られないことを狭幅の根拠にしない |
| ６場目から | 72時間の既定見出し窓と全既知の必要検索を分離。担当記録の機械配線を追加 | 母数と実読を混同せず、判断以外の手書きと重複確認を減らす |
| ７場目から | 独立した反証役を発行前に使用。引け準備と板寄せの制度を別入力 | 主導材料・既反映・経路の矛盾を点検し、代理値以後の観測不足を明示する |
| ８場目から | 為替・米株先物・原油・利回りの外部履歴を時刻別の別表示で追加 | 異なる時計の前日比からP0以後の変化を推測しない |
| 11場目から | 同じ原本・記事版の独立した連続区間を固定できる別入口 | 主文途中の関連記事を除外しつつ、必要な前後主文を保持。除外部分をまたぐ連結は拒否 |
| 12場目から | 過去の価格比較表へ主候補・初回到達/別足反転時計と出典SHAを追加。配当と先物の制度差も別入力 | 負の終点と道中の反発、現物の配当落ちと先物の再投資需給を分ける |
| 13場目から | 本人が決めた中心経路・主回答・想定帯を純計算で照合 | もみ合い優先など、発行前に検出できる数値の矛盾を減らす |
| 14場目から | 原案・対立案の成立／棄却条件を同じ基準で比較し、草稿と正式回答も別採点で蓄積 | 反証の採用自体を精度改善とみなさず、変更による悪化も確認する |
| 15場目から | 本人が主導材料・比較目的を事前指定し、時計ゲート済みの古い同系事例を追加検索 | 直近12場から外れた学びを、的中や値動きによらず材料一致順位・満了時計で最大6場補う |
| 16場目から | 反証は最大3点・0点可とし、規約違反・誤読・積極反証・未識別を分ける | 不確実性だけを原案撤回や対立採用の根拠にせず、本人が対称比較して採否する |
| 17場目から | CME日経先物の同系列変化を、時刻別の別表示で補助観測 | 国内P0と採点を置換せず、時計・限月の異なる絶対価格差を寄付ギャップ・D・点へ機械換算しない |
| 18場目から | 米半導体指数とMUの履歴を、閉場後の文脈も含む別表示で追加 | 実観測時計・経過分と鮮度上限1440分を明示し、現在価格や新取引へ読み替えず、同原因を多票や点へ自動換算しない。効果は未測定 |
| 18場目から | 締切までに利用可能な国内P0と同終端の外部足を別照合 | 朝は同終端比較を先に確認し、旧アンカー差を純P0後変化へ転記しない。夜は仮定配信前で不可、代用・Dや点への自動換算なし |
| 19場目から | 次book先頭の前場引け近傍quoteを別の補助観測として追加。正本は状態確認を行うv2 | 状態未確認の候補価格を表示しない。価格時計による開発再構成・受信時計欠如・CSV側の限月未記載と一致未確認を明示。P0/採点を置換せず、公式closeやD点へ自動変換しない。効果は未測定 |
| 20場目から | 結果開示後に予測本人が結果記事を選択し、終了時点の別切出本文を実読。最大3材料群をSHA付きで反応更新 | 予想と実績・予定と実公表・記事時計・P0比と予定近傍観測比を分離。未取得はnull、旧case・予測・独立認定は変更しない |
| 21場目から | 結果レビューの材料タグを別viewで引き継ぎ、旧予測材料と一つの事例検索へ統合 | 満了・版・根拠時計・本人読了を照合し、基底12場＋事前queryの追加最大6場を保持。元case/点/採点は変更しない |
| 22場目から | 開示後に本人が材料時計を先指定し、凍結helperで同先物の直前観測と5・15分後の厳密終端を比較 | 実公表不明は予定近傍のみ、P0比と直前比・経過秒・欠測を分離。元20・21の観測や採点は変更せず、因果を自動認定しない |
| 23場目から | 当回の承認済み反応viewだけから同じDay/Nightの直近最大6場の観測幅下限を比較 | 満了時計順で選び、勝敗・方向・幅で選別しない。中心幅や帯との実数比較を本人が行い、中央値への機械合わせ・真の通常幅・点や方向の自動生成はしない。効果は未測定 |
| 23場目から | 振り返りの最大6本文は主要予定結果の最大2枠を先に、一般市況・主導材料を残る最大4枠へ優先配分 | 予定結果が未収録なら検索範囲と不足を残して枠を埋めず、実公表や実績を推測しない。既存reviewとcaseは変更しない |

- 25場目から、中心の寄付き・初極値・終点を残存期待と反対観測へ個別に結び、同場の狭幅支持と反証を対で確認する開発補足を追加。方向や点を自動変更せず、効果は未測定。
- 25場目から、結果材料引継ぎは別版v2で任意のMarkdown等の補足出典も完全SHA照合。必須JSON・可知時計・本文・読了の検査は維持し、旧helper/ケース/採点は変更しない。
- 25場目から、振返CLI前に本人MDと正規振り返り.mdの同一bytes、固定JSON未存在、開示段階を確認する。第24場の名前差による部分停止は元成果を保全した別来歴で接続済み。

- 反証役には予測締切の入力だけを渡す。窓内の認定記事・結果は渡さず、回答の採否は予測本人が記録する。
- 外部履歴は後日取得版で、初配信・訂正履歴なし。５分足終端＋30分は開発仮定、60分を超える古い観測は比較未算出。原本や現在ページの相場本文は担当へ渡さない。
- 反応の更新では、終点・途中の反転・幅を分ける。分類が正解でも理由や高安が外れた場合を残す。
- 確定できない経路を正解へ繰り上げず、公式引け・限月・欠測の不足は維持する。
