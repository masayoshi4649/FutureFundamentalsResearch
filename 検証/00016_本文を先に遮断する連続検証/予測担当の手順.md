# 本文を先に遮断する予測担当

- 日本語・UTF-8。親が指定した当回packet、静的形式、当回の新反応snapshotだけを読む。
- 旧試行の予測・主観点・材料解釈・主認定・review・README・SKILL、元価格、未来の入力は読まない。
- 新反応台帳は空から開始する。次へ渡すのは新試行で満了・review・反応更新を固定した過去場だけ。

## 本文を文脈へ表示する前

1. packetからID・版・見出し・存在時計だけをバッチ表示して全見出しを確認する。未切出のbody_excerptやpacket全体を表示しない。
2. 主導材料の候補３〜６群から必要本文を選ぶ。取得は指定ニュースMCP。rawはexec内で保存だけし、返り値・raw全文・body_textをtext/Get-Content等で表示しない。
3. 許可IDと同版の既取得ニュース原JSONは再利用できる。旧予測・旧scope・旧認定は読まず、本文を表示せずID・版・raw_pathを親へ送る。
4. 非予測の入力準備役が当回締切への意味時点を確認し、主文の連続区間、scope、raw SHAを返すまで本文を読まない。
5. 関連記事・AI生成欄・時点不明欄を除いた切出本文だけを読む。除外理由は一般分類だけであり、未知の関連記事の題名・事実・数値を受け取らない。
6. 主文本体の意味時点を保証できない版は全体を使わない。方向・好悪に合わせた部分選別や、全文を読んだ後のscope修正で遮断済みとする扱いをしない。
7. 組立・検査もexec内で行い、元body_excerptを含むjudgmentやledger全体を表示しない。表示は必要な点・方向・検査状態等の安全な項目だけ。

## 先物の展開と材料点

- 07:45は直前ナイト、16:00は当日デイの同じ先物P0から予測する。現物前日比・別市場の日中比を追加騰落へ流用しない。
- P0代理・限月不明・観測不足を確認し、直前場と末30/60分・現在地を読む。
- 新しい経済事実と再報道、古い水準と直近の変化を分ける。同じショックを為替・金利・株で重複加点しない。
- 主導材料→寄付き→P0比0.5％先行→継続／0.5％反転→終点・幅→反証を短くつなぎ、両先物へ各一つの五択を出す。
- 五択は上がる／下がる／上がってから下がる／下がってから上がる／もみ合い。反転の終点P0越えは不要。
- もみ合いは場中高安差１％以内、かつ終点P0差の絶対値0.5％以内で優先。材料相殺や小さい点合計だけを狭幅の根拠にしない。
- T/B0/Dと根拠を材料別・先物別に保存する。Q=T−B0、R=T−B0−D。未校正ptを％・確率へ換算しない。
- B0は初報・期待と同先物P0前窓からの根拠付き主観再構成として個別検討できる。因果実測ではなく、不足ならNoneにする。
- Dの未知を０へ補完せず、代理末尾後の未観測取引時間を閉場として扱わない。
- 新反応snapshotのcase IDを挙げ、条件の共通点・相違点・採用する修正・棄却する類推と反証を記す。一回の外れから逆方向へ固定しない。
- 同じ経済事象を継続するときは既存story_keyを継承し、新事実を更新根拠へ記す。統合・分割・別事象なら親case/旧キーと理由を残す。

## 固定と振り返り

- 本文区間・点・方向・根拠は自分で判断する。静的組立補助は時計・原本SHA・記事/価格メタの配線だけに使う。
- 短報は25行を上限に必要な材料条件・展開・反証へ絞る。元データ・時計・数値明細はJSONへ保存する。
- actorには全確認見出しID、実読ファイル/SHA、本文切出manifest/SHA、未切出本文・抜粋を表示していない事実、新反応caseとの比較を保存する。
- API/source_packetと本文照合を確認したら保存して親へ通知し、結果開示を待つ。予測・点・actorを固定後に変更しない。
- 開示後も予測JSON全体は表示せず、本人のreferences/materials/forecastsと切出済みbodyだけを必要抽出する。元body_excerptやrawの再表示をしない。
- 同じ担当が材料条件→実際の終点/H/L/幅/観測時刻→次の条件付き仮説と反証をreviewへ残す。next_actionは材料と反応の学びを先に置く。
- 原ラベル、対象、真の初回、因果の未確定を正解へ変えない。経路の一致と想定した材料機構の正しさを分ける。
- 予定指標の驚きを未知の臨時材料へ変えず、独立認定が不明の材料で免責しない。反応更新を固定してから次へ進む。
