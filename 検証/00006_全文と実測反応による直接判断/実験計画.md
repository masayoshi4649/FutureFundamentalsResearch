# 循環10：全文と実測反応による直接判断

- 変更：四つの主観的材料点への圧縮をやめ、全文と既反応量を独立担当が直接読む。
- 日程：既存の2026/9/30〜10/15の９日、07:45・16:00、計18回。
- 目標：NK225・TOPIX別に方向一致80％以上。全回発行・保留０。
- 方向：上昇・下落・横ばい。実績境界は±0.05％、境界ちょうどは横ばい。
- 07:45：同じ先物の直前Night最終観測値→当日Day終点。
- 16:00：同じ先物の当日Day最終観測値→次Night終点。
- 価格は１分足の最終観測代理。引け板寄せ・受信履歴・限月継続は未確認。
- 当回入力：締切以前の全文、固定基準・経験分布、実測先物状態、記事中の市場観測。
- 初期教師：評価前に満了した12セッション×２先物の24行。評価分母に含めない。
- 引継ぎ：締切より前に満了した自分の過去振り返りと教師のみ。
- 各回で新しい担当を `fork_turns:none` で作成。過去の会話を継承させない。
- 担当の読取は当回入力１JSONと静的指示のみ。別回・原実績・ウェブ・追加ニュースは禁止。
- 担当の予測JSON完成→担当証跡と予測を固定→原結果読取→短い振り返り→次回。
- 担当の再利用・結果を見た作り直し・未知材料による外れの除外は禁止。
- 保存：18本の予測MD、18本の振り返りMD、担当・入力・予測・段階監査・集計。
- 数値レンジは固定済み同基準の当日経験分布を流用。長期・確率は今回未実証。
- 基準比較：全18回の常時上昇・常時下落・直前先物方向追随。
- 80％未達は不採用。既知期間の再利用なので80％でも独立検証の合格にはしない。
- 入力分離は手順上の対策。OS隔離、モデル内部の将来知識排除は証明しない。
