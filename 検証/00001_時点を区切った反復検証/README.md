# 時点を区切った反復検証

- 判定：[80％目標に対して不合格](判定追記.md)。予測方式の完成とは扱わない。
- 入口：[総括](総括.md)。各回の予測・振り返りへのリンクも掲載。
- 条件：[検証条件](検証条件.md)。結果を開く前に固定。
- 長期：[長期追跡](長期追跡.md)。初回に未満了だった週・月・３か月を別記録。
- 正しさ：[監査結果](監査結果.md)。情報時刻、順序、固定ファイル、採点対象を確認。
- 比較：[精度の確認](精度の確認.md)。日中・夜間、保留、単純基準を分けて比較。

## 保存順序

- 入力切出し→別文脈の予測担当→`予測.md`を固定。
- 実績開示→`振り返り.md`を固定→次回入力へ知見を引継ぎ。
- 前回の固定予測は修正しない。

## 読み方

- 当日方向：直前の同じ先物セッション最終観測値から測定。
- 保留：的中に数えない。横ばい予測とも区別。
- 範囲：過去価格の経験分布。ニュース条件付きの校正済み区間ではない。
- 週以降：元の仮説を保存したまま追跡。未満了は未評価。
- 総括は各回の即時振り返り時点。週の満了後の結果は長期追跡を参照。
- 記事原本・価格証跡・機械用JSONは版管理対象外。
