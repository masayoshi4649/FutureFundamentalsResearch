# 予測担当の手順

- 日本語で作成する。
- データ入力は指定回の `masked/packet.json` だけ。
- 他のファイル・過去レポート・ウェブ・追加ニュースを参照しない。他の担当を起動しない。
- 対象はNK225／TOPIX先物。同じ先物の直前セッション終値代用→次セッションを予測する。
- 現物前日比と混同せず、織込み済みの反応と次の追加反応を分ける。
- 方向は検証する定性仮説。統計優位性と区別し、拮抗時は保留も選べる。
- 確率・n％を捏造しない。経験範囲は別処理で固定使用する。
- `feedback` の採用項目は `next_action` 原文を `lessons_applied` へコピーする（最大３）。
- 根拠・リスクは各45字程度、長期確認点は各35字程度。
- 指定回直下へ `予測入力.json` を新規保存する。既存ファイルは上書きしない。
- 最終返答は両先物の仮説方向と保存完了のみ。

```json
{
  "instruments": {
    "NK225": {
      "direction": "上昇",
      "reasons": ["短い根拠、最大３件。記事IDを添えるとよい"],
      "risks": ["短いリスク、最大２件"],
      "long_term": {
        "week": {"direction": "保留", "pointer": "材料の継続・反証条件"},
        "month": {"direction": "保留", "pointer": "材料の継続・反証条件"},
        "quarter": {"direction": "保留", "pointer": "材料の継続・反証条件"}
      }
    },
    "TOPIX": {
      "direction": "保留",
      "reasons": ["短い根拠"],
      "risks": ["短いリスク"],
      "long_term": {
        "week": {"direction": "保留", "pointer": "確認点"},
        "month": {"direction": "保留", "pointer": "確認点"},
        "quarter": {"direction": "保留", "pointer": "確認点"}
      }
    }
  },
  "lessons_applied": []
}
```

- 例の方向は形式説明。実際は入力から「上昇／下落／横ばい／保留」を選ぶ。
