# 五分類評価の準備

- 変更理由：ユーザー指定の対象0.5％・対象内無回答は不正解・五つの回答へ対応。
- 目標：NK225先物・TOPIX先物でそれぞれ80％以上。
- 状態：対象・反転・もみ合い優先の確認を受領。**新基準の精度は未測定**。
- 旧実験の予測・採点・レポートは変更していない。

## 確定済み

- 基準は同じ先物の前セッション終値。現物前日比を使わない。
- 回答は上がる／下がる／上がってから下がる／下がってから上がる／もみ合い。
- もみ合いは場中高安差１％以内、かつ終点の前終値差が絶対0.5％以内。
- 対象の0.5％以上、もみ合いの１％以内・0.5％以内は境界を含む。
- 対象内の無回答を不正解とし、発行率を下げて80％を作らない。

## 確定した追加条件

- 対象は場中の前終値比±0.5％への到達を含む。
- 先行変動0.5％、ピーク／谷からの反転0.5％。終点の前終値越えは不要。
- もみ合いを優先して一つに分類する。
- 複数往復の実装規則は最初の±0.5％到達方向→最初の0.5％反転。実績に有利な往復を後付け選択しない。
- 規約・計画・担当手順を次の新実験で固定し、各回の予測→満了結果→個別考察を順次行う。
