# 旧検証の五分類への移行監査

- 範囲：旧定性予測＋循環１〜10の11方式、各18締切・２先物、計396回答記録。同じ市場時点は18件。
- 結論：旧記録は終点の上昇・下落・横ばい・保留。新しい五択を事前に回答した記録はなく、忠実な五分類への一括変換はできない。
- 旧「上昇」は、そのまま上がる場合と「下がってから上がる」を区別しない。旧採点の「横ばい」は終点±0.05％で、場中幅１％条件を含まない。
- 理由文の「下落後の反発」は、直前Night→当日Dayなど別セッションを指す場合がある。当該場の将来経路へ読み替えない。
- 旧価格経験帯も確率的な範囲であり、五択の回答へ後付け変換しない。結果を見て文章を有利に解釈し直さない。

| 入力 | 保存先・項目 | 移行時の用途 |
| --- | --- | --- |
| 基準・締切・終点 | `00001…/<回>/予測.json` の `as_of/targets/instruments.*.reference` | 同じ先物の基準を維持 |
| 元実績 | 同回 `result.json` の `labels[]` | 終点騰落、代理時刻、原本ハッシュ |
| 時系列 | `../FutureAlgorithmResearch/candle_1min/{NK225,TOPIX}/<session>.csv` | 場中高安、閾値到達順、欠測確認 |
| 旧回答 | 各方式 `<回>/予測.json` の `instruments.*.direction` | 原回答と固定ハッシュを保存。新五択と別仕様 |
| 直接判断の説明 | `00006…/<回>/予測.json` の `already_reacted/additional_reaction` | 文脈の点検用。経路回答の捏造に使わない |

- 重要：旧 `low_pct/high_pct` は前セッション基準価格自体も高安へ含める。新しい「場中高安差」は当該場の観測H/Lから再計算する。幅が異なる例は各先物５回。
- 下表はP0＝直前の同じ先物基準価格とした観測値の入力点検。対象条件と分類優先順位は未確定で、新五分類の成績ではない。

| 条件候補 | NK225／18 | TOPIX／18 |
| --- | --- | --- |
| 終点とP0の絶対差が0.5％以上 | 12 | 11 |
| 場中のP0比±0.5％への到達 | 17 | 17 |
| 場中H-LをP0で割った幅が0.5％以上 | 18 | 17 |
| 場中幅１％以下かつ終点絶対差0.5％以下 | 3 | 5 |

- 途中欠測はNK225が11/18回・計478分枠、TOPIXが12/18回・計256分枠。全終点は４〜５分前の代理。実際の全約定経路の完全性は未確認。
- 観測で閾値到達した回は到達を確認できる。欠測中の非到達や反転なしは断定しない。
- 同一１分足でP0の上下0.5％を両方跨ぐ足は今回０本。ただし反転定義によっては足内の高安順が不明になる。５分足・板だけで約定順を補完しない。
- 未確定事項：対象が場中到達か終点か、反転幅・終点クロスの要否、複数反転時の分類、もみ合いとの優先順位。確定前に新ラベルや的中率を作らない。
- 新規評価：対象かつ無回答・無効回答は不正解として対象分母へ残す。非対象件数も表示する。
- 実績欠損・順序不明は予測の無回答と区別し、対象不明／ラベル未確定として件数を残す。黙って非対象や採点済み件数へ移さず、未確定を残して80％達成としない。
- 旧三分類は `legacy_incompatible` として原仕様のまま保存。必要なら旧終点方向だけの参考比較を別表にできるが、五択正答率とは呼ばない。
- 新しい保存項目案：`rules_hash/forecast_hash/answer/answer_status/eligibility_status/actual_class/label_status/hit/reference/price_hash`。五択原回答、適格性、真値の可否を分ける。
- 保存は新実験に限定し、旧予測・旧採点・旧MDは上書きしない。入力点検の詳細は `local/PDCA改善/五分類_価格入力点検.json`。
