- 回想専用。当時の受信・評価記録時刻を再現した運用成績ではない。

```powershell
python -m fundamentals.pdca_research --root <固定入力ルート> --source <原実績ルート> --cycle <新しい循環名> --method ridge_scaled --initial-history <最初の締切より前に満了した教師JSON>
```
