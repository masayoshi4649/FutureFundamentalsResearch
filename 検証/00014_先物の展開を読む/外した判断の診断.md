# 外した判断の診断

- 対象は00013の9/21ナイト。結果を見た後の診断であり、元予測を修正しない。
- 問題は、材料点を作った後に「市場が現在どの材料を選んで動いているか」を展開予想へつなげなかったこと。
- 当時既知の記事418652には米株先物高・金利低下・ハイテク買戻しがあった。古い金利高の負担と新しい改善を分ける必要があった。
- 記事420202のドル円157円台の底堅さに対しても、介入警戒の存在をそのまま追加の下押しへ残していた。
- AI材料のNK225総影響+3ptに対し、+2.5ptを既反映とした。直前上昇だけでは消化完了と買い継続を識別できず、この配分の根拠が弱い。
- 合計−1pt／−1.5ptから、終点±0.5％以内・場中幅１％以内を支える根拠なしに「もみ合い」を選んだ。
- 金利・為替・原油に共通する原因を、複数の独立した下押し証拠として重ねる危険もあった。
- 以上は予測判断の不足。夜間上昇の真の原因、B0の真値、後発材料による免責を結果だけから確定するものではない。
- 次回は主導材料を絞り、P0までの反応と次の場の追加反応、寄付き・継続／反転・終点・幅を個別に判断する。
- [判断手順](../../docs/先物の展開予想.md)を固定して9/22デイから別記録で試す。新方式が当たると検証前に断定しない。
