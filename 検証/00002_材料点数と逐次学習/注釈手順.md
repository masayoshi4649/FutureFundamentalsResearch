# 注釈担当の手順

- 日本語・UTF-8。指定された切出済みpacketだけを読む。
- 結果、過去の予測、原本フォルダ、ウェブ、別担当への問い合わせは禁止。
- 指定順に１回ずつ読む→annotationsへ新規保存→次のpacketを読む。
- 前の注釈は変更しない。後のpacketを先読みしない。
- 予測対象は先物前セッション最終観測値からの追加変動。
- 記事が説明する過去の上げ下げを次の予測リターンへ重ねない。

## 材料の分類

- growth：需要・業績・半導体など。割引率、為替、原油の点数は重複させない。
- discount：金利・物価・金融政策。
- fx：為替による指数別の影響。
- cost_risk：原油・供給・地政学・リスクプレミアム。
- NK225とTOPIXの影響を別々に判断する。共通記事でも同じ符号と決めない。
- score：先物の次セッションへの方向点数。-1〜+1。
- confidence：根拠の明確さ。0〜1。方向の的中確率ではない。
- novelty：今回の新規性。0〜1。再報だけなら低くする。
- priced_in：直前セッションまでに反映済みと考える割合。0〜1。注釈仮説であり観測値ではない。
- evidence：当回packetの実在記事ID。最大３個。根拠なしなら空配列、scoreとconfidenceを0。
- reason：追加反応・新規性・織込みの判断を日本語40字程度で記す。
- 反転根拠なしに大幅安だけで反発とせず、新規材料なしに悪材料を繰り返し加点しない。

## 保存形式

```json
{
  "as_of": "packetと同じ日時",
  "instruments": {
    "NK225": {"channels": {
      "growth": {"score": 0, "confidence": 0, "novelty": 0, "priced_in": 0, "evidence": [], "reason": "根拠なし"},
      "discount": {"score": 0, "confidence": 0, "novelty": 0, "priced_in": 0, "evidence": [], "reason": "根拠なし"},
      "fx": {"score": 0, "confidence": 0, "novelty": 0, "priced_in": 0, "evidence": [], "reason": "根拠なし"},
      "cost_risk": {"score": 0, "confidence": 0, "novelty": 0, "priced_in": 0, "evidence": [], "reason": "根拠なし"}
    }},
    "TOPIX": {"channels": {"growth": {}, "discount": {}, "fx": {}, "cost_risk": {}}}
  }
}
```

- TOPIXも全channelに同じ７項目を必ず埋める。
- 保存先は指定されたannotationsの当回JSONだけ。上書き禁止。
- 予測の方向や結果は生成しない。モデル側で固定した算出式を使う。
