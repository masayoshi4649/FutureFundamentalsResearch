# 満了後の当日価格を追加する

- ローカル未収録でも、親リポジトリに記載された読取APIが現セッションを収集中の場合がある。
- APIと共有フォルダは2026/10/16に読取確認。共有の１分足は各38場で、9/21より前の追加履歴はなかった。
- 下記は公式終了予定が過ぎた後だけ取得する。満了前はHTTP要求の前に拒否する。
- 元価格を変更せず、過去CSVのコピーと当日のAPI原本・変換CSVを新しい価格ルートへ保存する。
- APIのセッション・先物・スナップショット時計・終了予定を照合。確定足だけを採用し、終点後の足は除外する。
- 出来高の完全性は確定フラグと別に保持。公式終了予定10分以内の最終１分足を代理として評価する。
- 保存済みファイルは上書きしない。対象日・未使用保存先は実行ごとに指定する。

```powershell
python -X utf8 -m research_support.acquire_current --source ../FutureAlgorithmResearch --out local/追加価格_20261016 --session 2026-10-16_Day
```

- `取得証跡.json`に元CSV・コピー・API原本・当日CSVのハッシュ、取得時計、収集側スナップショットを保存する。
- 00004の固定予測を照合する場合は、満了後に追加ルートを明示する。

```powershell
python -X utf8 -m fundamentals.pdca_pending evaluate --root 検証/00004_結果未開示の追跡 --prices local/追加価格_20261016
```

- 取得元が次セッションへ切り替わった場合や末尾足が足りない場合は取得を拒否し、別価格で補わない。
- 実際に10/16 15:45後のAPIは次セッションへ切り替わった。親リポジトリ記載の共有へ確定保存されたCSVを、読取前後のサイズ・更新時計・ハッシュを確認して取得できる。

```powershell
python -X utf8 -m research_support.acquire_current --source ../FutureAlgorithmResearch --out local/追加価格_20261016 --session 2026-10-16_Day --archive '\\10.10.100.1\log'
```

- 共有元も読取専用。書込み中のファイル・既存保存先・別場・終了10分超の代理は拒否する。API不一致を任意価格で埋める処理ではない。
- このAPIを任意の長期履歴の取得手段とはみなさない。外部通知・注文・定期起動は行わない。
