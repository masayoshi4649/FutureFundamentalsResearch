# 精度の合格条件：五分類への変更

- 2026年10月16日の追加指定：**0.5％以上動いた回を主対象にし、各先物で正解率80％以上**を目標とする。
- 対象となる回の無回答・保留は不正解。回答を出した回だけの勝率で代用しない。
- 対象はNK225先物・TOPIX先物。現物指数の前日比を採点に使わない。
- 07:45は直前ナイト、16:00は当日デイの同じ先物終値が基準。
- 現行CSVは公式終値を含まず最終観測値による代用。価格・時刻・欠測を表示する。

## 回答

- 上がる
- 下がる
- 上がってから下がる
- 下がってから上がる
- もみ合い：**対象セッションの高値安値の差が１％以内、かつ終値の前セッション終値からの絶対変化が0.5％以内**。境界を含む。

## 確定した採点規約

- 対象：場中に前セッション先物終値から上下いずれか0.5％以上へ到達した回。終点だけでは判定しない。
- 反転：先に前終値比0.5％以上動き、その後の高値／安値から0.5％以上反転。終値で前終値を越える必要はない。
- もみ合い条件を満たせば、反転条件と重なっても**もみ合いを優先して一つに分類**する。
- 高安差・反転幅の百分率は同じ先物の前セッション基準価格を共通分母にする。基準価格自体を場中高安へ算入しない。
- 複数往復の実装規則：もみ合い以外は最初に±0.5％へ到達した方向を起点とし、その後の最初の0.5％反転で分類する。後から成立した有利な方向を選ばない。
- 反転がない場合は最初の到達方向に従って上がる／下がる。到達順・反転有無を証明できなければ未確定とする。
- 規約と[監査](../検証/00009_五分類評価の準備/README.md)を別実験へ固定する。
- [算定例](五分類の算定例.md)で、終値が戻る場合・複数往復・もみ合い優先を確認できる。

## 保存・集計

- 予定全回で回答を先に固定し、満了後の実績で対象性を判定する。対象外の回答も残す。
- 各先物・日中夜間別に、全予定数、対象数、対象外数、対象不明数、無回答数を示す。
- 主成績は正解数／対象数。対象内の無回答は分母に残す。
- 足内順序や欠測で判定できない回を黙って除外せず、確定正解と可能正解を分ける。対象不明も含めた保守的な精度を併記する。
- 未確定の回を全て正解にして80％達成とは記さない。
- 後発材料を理由に失敗を除外しない。
- 規約・対象期間・規則を先に固定する。既知期間での再調整は開発実験で、未使用期間の確認とは別。
- 同じ対象回の単純基準と比較する。反復試行数、標本数、同日・同材料の依存も示す。
- 価格レンジの80％包含と五分類の正解率80％は別の指標。

## 旧検証

- [旧三分類の合格条件](精度の合格条件_三分類.md)は履歴として保存。
- 旧実験の±0.05％横ばいは終点だけの条件。新しいもみ合いへ読み替えない。
- 旧予測・旧結果は変更せず、新しい五択の回答を別実験で固定する。
- 新基準の正解率はまだ未測定。旧三分類の数値を五分類の成績として表示しない。
