# 足の未収録と無約定

- 元CSVのない分を、無約定または収録漏れのどちらかへ決め付けない。既存の欠測数・P0・採点は保持する。
- 現在の[`future_history_candles.go`](../../kabus-controller/future_history_candles.go)では、受信分と価格時計の分が一致する有効価格だけで足を形成する。空の分は作らず、確定後の足への遅着価格を除外する。
- `closed=true`は形成済みの足が時間境界を過ぎた意味で、全約定の収録証明ではない。
- `volume_complete=true`は累積出来高の基準を取得済みで、当該処理でリセットがない意味。価格経路の欠測なしを保証しない。
- [`future_history_store.go`](../../kabus-controller/future_history_store.go)は内部に受信時計・連番を保持するが、[`future_history_archive.go`](../../kabus-controller/future_history_archive.go)のJSONL出力は生payloadだけ。現ファイルから正確な受信間隔を復元できない。
- 実例：既開示9/28Day・TOPIXのCSV未収録11:37について、生板128,453行にもその分の有効な価格時計はなかった。直前11:36:40→直後11:38:01。無約定・通信停止・遅着のどれだったかは確定できず、穴埋めしない。
- 出典：`local/本文遮断連続/生板の欠測時計照合_20260928_Day_TOPIX.json`。全22先物場の未収録時計は`欠測時間帯_開示0011.json`。この時計監査は第11場までだけで、未開示の価格を読んでいない。
- 生成コードは現在取得版で、関係コミットは2026/10/9。各過去収録時の稼働バイナリ・設定との一致は未確認。原文とSHAは`local/本文遮断連続/足生成方式の監査/`へ保存。
- 今後は受信時計・連番・商品と限月・接続状態・引け状態を別記録する。生板を再集計する場合も同じ市場情報の再利用であり、独立した価格源と呼ばない。
