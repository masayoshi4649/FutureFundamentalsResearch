# 配当と先物の基準価格

- 先物理論価格は、満期までの予想配当を事前に控除して形成される。現物の配当落ち額を、そのまま同じ先物のP0後の下落へ足さない。[大阪取引所・第19話、2018年8月掲載](https://www.jpx.co.jp/derivatives/market-report/column/nlsgeu000005dfr7-att/019_column.pdf)
- 夜間の変化も、同じ限月の先物同士で比較する。現物と先物の価格差には配当などの制度上の差が含まれる。[同資料](https://www.jpx.co.jp/derivatives/market-report/column/nlsgeu000005dfr7-att/019_column.pdf)
- 配当再投資に伴う先物買いは別の需給仮説。規模・実行時計・P0までの反映を記事等で確認し、予定があることだけで寄付きから引けまでの上昇を決めない。
- 予想配当額の変更、配当落ちの仕組み、再投資需要、既反映を分けて記す。制度の説明だけから材料点・方向・値幅を生成しない。
- 2018年資料の取引時間や権利日の営業日表現を、現在の具体的日程へ転用しない。現在の日程は当該年の公表資料で別確認する。
- [JPXのETF説明](https://www.jpx.co.jp/equities/products/etfs/risk/)でも先物と現物の配当落ちの違いを確認できる。ただし現在ページを過去予測の当時本文として使わない。
- 過去検証へ制度入力を加える場合は、[掲載一覧](https://www.jpx.co.jp/derivatives/market-report/column/index.html)の公表月、資料SHA、採用回を記録する。過去版の一致と正確な公表時分は未確認と明示する。
- 元資料・取得記録：`local/本文遮断連続/制度資料/配当と現物先物差/`。予測には一般原理の短い別入力だけを渡し、現在ページ全体を表示しない。既存予測・P0・ラベルは変更しない。
