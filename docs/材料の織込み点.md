# 材料の影響点・織込み点・残余点

## 目的と単位

ニュースを材料群ごとに整理し、NK225先物とTOPIX先物について、材料の影響、前セッション基準価格への既反映、その後の反応、残余を独立に示す。点数を付けた根拠と、未確認の箇所も読める台帳を作る。

単位は主観的な分析ポイント `pt` とする。正は対象先物を押し上げる仮説、負は押し下げる仮説である。日経平均の指数ポイント、価格の円、百分率リターン、確率、観測できる真の織込み率とは別の単位である。点数を100倍して百分率表示したり、残余点を価格へ直接換算したりしない。

総影響点は−5から+5の同じ尺度を両先物に使う。絶対値0は相殺後の方向寄与が中立、1は弱い、3は中程度、5は非常に強いという注釈上の目安であり、値動きの大きさへの対応は未校正である。0と未識別の `null` は区別する。確信度は根拠の強弱として説明し、点数へ再乗算して隠さない。

## 一つの材料群と二つの時計

同じ政策、統計発表、企業情報等の経済事象を一つの `story_key` に束ねる。初報、転載、続報、解説をそれぞれ独立の材料として足さない。実質的な変更があれば新しい判断版を保存するが、元の材料群を維持する。

- `P0`：同じ先物の前セッション観測最終値。07:45では直前ナイト、16:00では当日デイ。価格、実観測時刻、セッション、限月の確認状態、出典、正式終値の代理であることを固定する。
- `as_of`：当回の情報締切。公表・取得・有効時刻がここまでの資料だけを使う。現在作成した採点の記録時刻は別に保存する。

P0当時に実際に保存した台帳がある場合はその版を参照し、後の実績や記事で上書きしない。当時台帳がない場合の「P0までの既反映点」は、当回に再構成した仮説と明記する。その根拠にはP0以前に利用可能だった期待・記事・同先物価格だけを使い、「P0時点で保存済みの判断」と装わない。

## 点数の計算契約

材料群・対象先物・予測期間ごとに、計算入力は次の三つだけとする。

| 記号 | 入力キー | 定義 |
| --- | --- | --- |
| `T` | `impact_pt` | 最新の可視情報から判断した総影響点。事前期待を引く前の、当該材料がない比較状態に対する目標時点の作用仮説 |
| `B0` | `priced_in_before_reference_pt` | P0までに同じ先物へ既に反映したと判断する符号付き点数。期待に基づく先行反映と、初報後からP0までの追加反応を含む |
| `D` | `priced_in_after_reference_pt` | P0からas_ofまでに同じ先物へ追加反映したと判断する符号付きの**増分**。as_ofまでの累計ではない |

以下は計算で導出し、独立の手入力値で上書きしない。

Tの根拠には比較状態を明記する。たとえば政策維持、既存の利益見通し維持等であり、同じ材料のT・B0・Dで比較状態と尺度を変えない。

```text
as_ofまでの既反映点        B = B0 + D
P0基準の残余寄与           Q = T − B0
as_of以後の残余点          R = T − B0 − D
分母をそろえる恒等関係     Q = D + R
```

利用者向けには、少なくとも「総影響T／P0までB0／P0後D／既反映合計B／P0基準Q／as_of以後R」を並べる。P0から目標までを予測・採点するとき、説明する寄与はQである。RだけをP0基準の値動きへ対応させると、P0後に既に生じたDを二重に引いてしまう。

B0とDは総影響を超えたり、総影響と逆符号になったりしてよい。過反応・逆反応の可能性を残すため、0から1の割合へ押し込めない。ただし、その解釈を根拠付きで記す。`B/T` を計算できても真の織込み率として表示しない。Tが0なら比率は定義できず、符号が違う場合も割合の解釈は成立しない。

### 事前期待と発表後反応を二度引かない

事前予想・市場で語られていた見込みと、発表後の価格反応は別の証拠である。B0の根拠文は「期待の先行反映」「初報後からP0までの追加反応」「重複を除いた理由」に分ける。期待に基づき初報前へ反映した部分と、実績が判明してからP0までに追加反映した部分を重ならない時間窓で考える。同じ下落を「期待済み」と「反応済み」の両方へ足さない。

Tを既に「実績−事前予想」に相当する驚きだけの点数へ縮めた後、さらに期待済み分をB0として引く定義は使わない。本契約のTは期待控除前である。事前期待が未取得なら、その不足を記し、単に実績が良いことを理由に未反映の上昇余地を大きくしない。

旧形式の `impact × confidence × novelty × (1−priced_in)` は別版の仮説である。新形式でその積をTへ代入して再度B0・Dを引かない。転載の重複除外は材料群の統合で行い、新規性を再び掛けて二重に割り引かない。

### 閉場時の外部市場

07:45と16:00の標準実行では、通常P0以後の国内対象先物は閉場している。同じ先物の追加取引を確認できなければ、国内の追加価格反応を観測したことにはならない。為替、海外株、海外金利の変化を、同じ先物のDへ無条件に換算しない。

閉場による追加取引観測なしを根拠にDを0と注釈する場合は、その理由を記し、潜在的な公正価値も変わらなかったとは断定しない。外部反応は次の寄付きギャップ、業種差、追加反応の仮説を支える別欄へ置く。単なる価格欠損は閉場で反応なしと扱わず `null` にする。

## 根拠として残す内容

点数の理由は材料ごと・先物ごとに保存する。根拠を得られない欄は空欄や0で埋めず、`未取得`・`未識別`・`非該当`を区別する。

| 根拠 | 必要な記録 |
| --- | --- |
| ニュース | 初報の公表時計、記事版ごとの公表・取得・有効時計、記事IDと版、本文の保存範囲、原本ハッシュ |
| 事前期待 | 当時の予想・前回値・想定シナリオ、単位、対象期間、出典、その予想が存在した時計 |
| 実績と差 | 初回実績、後日改定との区別、予想と同じ単位の差。予想が欠ければ差は未算出 |
| P0前の反応 | 初報または事前期待の観測開始からP0までの同じ先物の実価格。比較窓、始終価格、欠測、限月確認状態 |
| P0後の反応 | P0以後かつas_of以前の同じ先物の始終価格と窓。記事の発表後区間かを区別する |
| 外部反応 | 為替・金利・海外株等の銘柄、通貨方向、始終時計、実測変化、出典、関連付けの仮説 |
| 伝達経路 | 利益・需要、コスト、割引率、円換算、リスクプレミアム、需給のどこを通じて各先物へ作用するか |
| 反対仮説 | 反証条件、相殺する別材料、重複する共通原因、失効時計と理由 |
| 後続予定 | 当時既知の統計・会見・決算等の名称、時計、出典、再評価する条件 |

観測リターンは根拠として百分率で表示できるが、同じ区間の値動き全体を一材料の因果効果と認定しない。複数材料が同時に出た窓では共通窓の識別子を付ける。政策、円、海外株が同じショックに反応している場合、その全変化を別々の材料へ加点しない。

窓自体の騰落率 `100×(終点価格／始点価格−1)` と、前セッション共通分母での変化 `100×(終点価格−始点価格)／P0` も区別する。異なる始点を分母にした窓騰落率を足してP0基準の騰落率にしない。どちらの観測値も、主観ptへ直接変換する係数を意味しない。

## 保存する構造

実装の入口は `research_support/material_points.py` の `build_material_ledger` と `render_material_markdown` とする。APIの形式は次のとおりで、原記事や旧固定予測を編集する処理にはしない。

```text
build_material_ledger(as_of, references, articles, materials, forecasts)
references[先物] = symbol, contract, price, time, session, proxy, source
materials[] = material_id, story_key, title, evidence,
              status, status_reason, expires_at, invalidation, offsets, impacts
impacts[先物][期間] = impact_pt, priced_in_before_reference_pt,
                     priced_in_after_reference_pt, evidence, transmission, observations
observations = before_reference[], after_reference[]
forecasts[先物][期間] = direction, author_kind, author, reason,
                      material_ids, point_rationale
```

記事への `evidence` は `id` と `revision_id` を持つ。三つの点数にも同名キーを持つ根拠文を付ける。観測がある場合は `symbol`、`contract`、`start`、`end`、`start_price`、`end_price`、`source` を持つ。前窓の終点はP0以下、後窓はP0以上からas_of以下とし、異なる限月を同一価格列として扱わない。限月未確認はその状態を表示し、同一限月を確認済みと記さない。

事前期待・実績差・初報時計・外部反応・後続予定は、取得済みの構造化資料を添付するか、根拠文へ時計と出典を明示する。これらの追加項目を実装が数理検証したことと、記述を保存しただけのことは分ける。点数とその根拠を束縛するハッシュは変更検知であり、当時存在したことや因果の正しさを証明しない。

自動検査の範囲は、記事・材料の識別、時計、観測窓、必須記述、点数の算式等とする。根拠文が経済的に正しいこと、価格反応をその材料へ帰属できること、記述した順序仮説が五分類に適切であることは、当回の判断と結果後の個別考察で別に確認する。

todayは両先物に用意する。week・month・quarterは期間別にT・B0・Dを考えるか、ブロック自体を `null` とする。当日の点数をそのままコピーしたり、平方根時間だけで延長したりしない。半減期を使う場合も当初の仮説と期間別の限界を記す。

## 五分類との接続

材料点は五分類の説明材料であり、合計点の正負から五分類を機械的に確定しない。反転には順序が必要である。「下がってから上がる」なら、先行する下押しの材料・フロー、P0比で最初に下側へ到達する仮説、その後に売りが弱まるまたは買いが強まる条件を別に記す。「上がってから下がる」も同様に二段階を説明する。

前ナイトの下落を、翌日中の「下がってから上がる」の先行下落へ流用しない。ナイト終値をP0とする日中予測では、対象の日中場内で下落と反発の順序を予測して初めてその分類を選べる。P0以前に下げており、対象場では追加上昇する仮説なら「上がる」の候補である。

もみ合いは単なる点数合計0ではない。強い上向き・下向き材料が相殺して0でも、場中に大きく往復し得る。現在の五分類規約の高安差・終点・最初の到達と反転、もみ合い優先に従い、価格経路の仮説を併記する。各回答は人間またはLLMの判断者、参照した材料ID、具体的な点数との対応理由を固定する。

予測時点に未知だった臨時材料の打切り認定は、この事前の材料点台帳と別である。予測後の臨時材料を過去のT・B0・Dへ追加しない。現行の[精度の合格条件](精度の合格条件.md)に従い、独立認定した公表前を主評価、全場の結果を参考として残す。予定済みイベントの予想外の結果は打切りに使わない。

## 説明用の例

以下は実在材料を採点した結果ではなく、符号と基準を確認するための仮例である。

| 仮説 | T | B0 | D | P0基準Q | as_of以後R | 読み方 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 悪材料が前ナイトでおおむね反応済み | −4 | −3 | 0 | −1 | −1 | 悪材料の総量と次場の追加下落余地を分ける |
| P0後に一部下落済み | −4 | −1 | −2 | −3 | −1 | P0基準の−3を、未来残余−1だけへすり替えない |
| 発表前の好期待に実績が届かない | +2 | +4 | 0 | −2 | −2 | 実績自体が良くても、期待との差では下押しの仮説になる |
| 想定以上に下げた可能性 | −3 | −5 | 0 | +2 | +2 | 反発の余地の仮説であり、反発の時刻・順序・成立を保証しない |
| 織込みの根拠が足りない | −3 | null | null | null | null | 総影響だけを出し、残余を捏造しない |

## 学術根拠と適用範囲

本点数の尺度、三点の差分式、主観採点の手順は本リポジトリの分析契約であり、下記論文が証明した価格算式ではない。

- ローカルの[マクロ経済学](S:/GitHub/masayoshi4649/MarketSkills/.agents/skills/pnd-forecast-japan-index-nt/references/教科書/マクロ経済学.md)は、実績・予想・改定を分け、政策と中央銀行の景況情報を区別する。[行動経済学](S:/GitHub/masayoshi4649/MarketSkills/.agents/skills/pnd-forecast-japan-index-nt/references/教科書/行動経済学.md)は、新規性、過少・過剰反応、事前に固定した参照点と反証を重視する。これらを参照し、既存スコアの係数を日本先物の実績へ移植しない。
- Kuttner（2000年公表稿、2001年刊行）は、政策変更の予想済み部分と予想外部分を先物から分けて反応を分析した。期待と発表結果を区別する根拠であり、NK225・TOPIXの織込み率を直接測った研究ではない。[ニューヨーク連銀の原論文案内](https://www.newyorkfed.org/research/staff_reports/sr99.html)
- Gürkaynak・Sack・Swanson（2004年公表稿）は、政策の現在の変更と将来経路の情報を分けた。単一の政策強弱点だけでは異なる経路を隠し得るという設計上の注意に使う。[米連邦準備制度の原論文](https://www.federalreserve.gov/pubs/feds/2004/200466/200466abs.html)
- Jarociński・Karadi（2020）は、政策ショックと中央銀行の情報効果を、高頻度の金利・株価共動から区別した。同じ金利上昇に一つの株価方向を固定しない根拠であり、見出しのみで識別できることを示すものではない。[出版社の原論文](https://www.aeaweb.org/articles?id=10.1257/mac.20180090)
- Tetlock（2008年公開稿）は、既知情報の再報道への反応を新情報と区別して分析した。転載の数を新規材料の強さへ換算しない設計に用いる。米国個別株の結果と持続期間を日本の指数先物へそのまま移さない。[著者公開稿](https://columbia.edu/~pt2238/papers/Tetlock_SSRN_Fit_to_Reprint.pdf)

公式・著者・出版社の公開資料は2026/10/16に確認した。市場反応の観測は因果識別とは別であり、この台帳の導入だけで五分類80％や将来の収益性が実証されたとは記さない。
