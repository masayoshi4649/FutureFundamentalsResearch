# 現物・先物の営業日を分ける

- 予測前に、国内現物、対象先物、主導する海外市場の営業日・取引時間を別々に確認する。
- 先物の祝日取引を現物休場の理由で母集団から落とさない。P0は同じ先物の直前場を使う。
- 現物休場中の業種別反応を観測したと仮定しない。観測できないことを弱材料・低変動の証拠へ変換しない。
- 日中の狭幅を、海外現物が開くナイト全体へ延長しない。取引時間・参加市場の違いを比較条件へ残す。
- 制度資料はニュース材料と分け、公式公表日、対象日、原本SHA、使用範囲を固定する。
- 公表が日付だけなら時分を作らない。日末上限と実初報を区別し、情報締切より前であることを検査する。
- 現在取得した原本と、当時の保存版との一致を未検証のまま断定しない。
