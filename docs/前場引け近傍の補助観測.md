# 次ファイルにある前場引け近傍の更新

- 00016の第19場以降に、別の補助表示として採用する。効果は未測定、過去の予測・P0・採点は変更しない。
- 生板ファイルは価格の対象場と一致するとは限らない。前場終了後の価格更新が、次場名のファイル先頭に残る。
- 開示済み17場・34先物回のうち29回で、次ファイル先頭2MiBに前場公式予定終端の１秒後の価格更新が見つかった。デイ16/16、ナイト13/18。
- デイ12回には一意の`CurrentPriceStatus=8`があり、一次仕様上の終値状態を確認できた。ナイトの検出13回は状態1で、終値状態を確認できていない。[APIの一次仕様](https://raw.githubusercontent.com/kabucom/kabusapi/master/reference/kabu_STATION_API.yaml)
- 表示するのは、当回ファイル先頭2MiB内の前場予定終端±５秒の価格・時計・商品名・限月・市場・状態だけ。締切後の価格時計や、他行・他の板項目は担当へ渡さない。
- 商品名・限月の形式・市場を検査する。複数の価格候補は選ばず不明、同じ価格の状態違いも独立した証拠へ数えない。
- 原価格時計の１秒を丸めない。既存CSVは公式引けを含まない最終観測代理で、基準P0はそのまま固定する。
- JSONLには受信時計がない。CSVと同じ価格時計を使った開発再構成であり、締切前の初配信・受信版を証明するものではない。
- 候補の欠如は、限定範囲での未検出または原本ルート未収録。取引なし・価格不変・公式引けなしと断定しない。
- CSVの限月未記載、公式引け・後続訂正の未確認を維持する。候補から国内D点・材料寄与・寄付き・確率を自動計算しない。
