# CME日経先物を補助に使う

- Yahooの`NIY=F`の5分足を、円建て日経先物の外部観測として使う。国内のNK225・TOPIX先物のP0や採点価格は置き換えない。
- 取得時の銘柄情報はCME・JPY・先物を示すが、現在の限月から過去の連続系列の限月を認定しない。現在の銘柄情報・価格を歴史予測へ配信しない。
- 履歴は後日取得で、初配信・訂正履歴と過去の限月は未確認。Datetimeは提供元のタイムゾーン付き足始端を採用し、CME公式時計と照合済みとはしない。
- 既存の純観測処理で、足終端＋固定30分が各アンカー以前、鮮度60分以内の足だけを比較する。30分は開発仮定で、当時受信の証明ではない。
- 国内P0・締切は比較用アンカー。採用した海外足の実終端を読む。P0アンカーに対応する海外足もP0より古く、純粋な国内P0後変化とは限らない。
- 同じ海外系列内の変化を、ニュースに対する海外反応・寄付き仮説の補助にする。国内先物と時計・限月がそろわない絶対価格差を、そのまま寄付きギャップにしない。
- 海外変化を国内のD、材料点、確率へ自動換算しない。Nasdaq・為替などと同じ原因に反応している場合は独立加点しない。
- 欠測・鮮度超過は先行補完しない。表示対象を増やしたこと自体を精度改善と記さない。
- 新00016では第17場以降に追加。既存入力や予測は差し替えず、後半の成績と手順変更時点を併記する。
