# 発表時計近傍の同先物観測

- 結果開示後、予測本人が最大３材料と時計を先指定する。指定原文の保存パス・SHAを入力へ結ぶ。元の予測・認定・採点・価格は変更しない。
- `local/本文遮断連続/発表近傍の観測を作る.py --round 対象回 --selection 指定.json --out 新規観測.json`。標準出力は保存先・SHA・行数のみ。出力は上書き不可。
- 指定は `session`、`selected_by`、開示後の `selected_at`、`selection_evidence: {path, sha256}`、１〜３件の `events`。各材料は `material_name`、`scheduled_at`、`actual_release_at`（不明はnull）を持つ。
- 実公表時計が既知なら必ずそれを基準にする。追加で `actual_clock_evidence: {path, sha256}` と `actual_clock_basis` を記す。根拠の意味は本人が確認する。記事公開時計を実初報へ代用しない。実公表不明なら「予定時計のみ」と表示する。
- 監査連鎖が開示／振り返り段階、対象場満了、結果SHA、同先物・当回・１分CSVのSHAを確認してから価格を読む。結果・指定・根拠・コード・本規則のSHAを読取前後で照合して出力へ保存する。
- 場内の確定足のみ。基準時計以前の最終終端closeと経過秒、基準から５／１５分後の厳密な終端closeを示す。終端が無い、未確定、場外ならnull。窓内期待・観測・欠測行数を表示し、補間しない。
- P0比と直前観測close比は別の分母。実足時計を併記する。秒付き発表では窓に完全に入る１分足だけを数え、厳密な終端が無ければ反応値を計算しない。
- 観測上の対応と単独因果を分ける。予定時計だけの観測を実公表後の反応と記さない。同時材料・欠測・古い直前値を本人が振り返る。
