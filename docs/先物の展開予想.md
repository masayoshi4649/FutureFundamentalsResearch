# 先物の相場展開を読む

- 目的：材料を並べるだけで終えず、同先物の前セッション終値P0から、次の場でどう再評価されるかを予測する。
- 07:45は直前ナイト、16:00は当日デイの同先物P0を起点にする。現物前日比・CMEの大阪日中比を追加騰落へ転記しない。
- 参考とする市況記事の構成は、冒頭の展開予想→海外材料の因果→価格・為替の接続→主導業種・需給→観察条件。
- 当日の締切後の記事・価格は使わない。構成の参考にした記事の具体的相場情報も、過去の予測担当へ渡さない。

## 判断の順序

1. **現在地**：同先物のP0、直前場の値動き・終盤の位置・欠測を確認する。既知価格と記事中の価格が食い違う場合、商品・限月・時計・比較基準の差を記す。
2. **更新**：金利・為替・原油・海外株の水準と直近変化を分ける。悪材料が存在しても改善中なら、古い下押しをそのまま残さない。P0前後をまたぐ変化を全て未反映としない。
3. **主導材料**：相場を動かしている仮説を１〜２群選ぶ。材料の件数で多数決せず、同じ原因の金利・為替・原油を独立した三重の証拠として加点しない。
4. **反応の読み**：悪材料でも下がらない、好材料で高値を保つ等の可視反応を確認する。直前の上昇だけで消化完了と断定せず、買い継続・反転の両仮説と根拠の強さを比較する。
5. **時間順序**：寄付きがP0からどちらへ動くか、先に±0.5％へ達する側、継続か0.5％反転か、終点と想定幅をそれぞれ記す。欧州・米国の取引開始や既知の予定発表も、締切時点で確認できたものだけを織り込む。
6. **先物別判断**：半導体・AI等の主導株と、銀行・資源・内需等への波及を分ける。両先物を機械的に同じ回答にしない。業種構成からの説明は仮説であり、未取得の指数ウェイトを捏造しない。
7. **点と回答**：[材料点の定義](材料の織込み点.md)に従いT/B0/D/Q/Rを示し、上記の展開予想を根拠として五択を一つ選ぶ。点数の合計符号を回答へ自動変換しない。
8. **反証**：主導材料が失効する条件、対立する展開、不足観測を具体的に残す。反証条件を主回答と並ぶ別の正解として事後採用しない。

## 誤りを防ぐ規則

- 「合計点が小さい」「強弱材料が相殺」は、もみ合いの根拠として十分ではない。場中幅１％以内と終点P0差絶対0.5％以内の両方を支える観測・仮説が必要。
- 「上がってから下がる／下がってから上がる」は、P0比0.5％の先行変動と、高安からP0比0.5％の反転までを予測する。単なる上値の重さ・下げ渋りでは選ばない。
- B0は期待分・初報後の反応を重複なく説明する。根拠がなければ不明を残し、記事が古いことや直前上昇だけで大部分を既反映としない。
- 外部市場の更新は国内先物の実測Dとは分け、再開時のギャップ仮説へつなぐ。時計の合う外部比較値がなければ変化量を作らない。
- 数値レンジは既知価格・比較窓等からの根拠を添える。未校正ptから％へ換算せず、主観シナリオと過去分布を区別する。
- 終値予想は各先物につき単一値で示し、同先物P0からの予想騰落率を添える。場中の想定変動レンジ・高安差は別欄に置く。終値の誤差は固定した単一値との価格差・P0比で記録し、場中レンジへの収まりや五分類の正答とは分ける。
- 当日の８時半頃の市況記事は07:45には未知。16:00には既知でも、その記事が説明したデイ場での既反応を差し引いてNightの展開を新しく判断する。
- 無回答を選ぶ場合も理由を保存し、対象回では不正解のまま数える。手順の改善を精度の改善とは扱わない。
