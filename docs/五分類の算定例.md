# 五分類の算定例

- 前セッションの同じ先物終値を100とした、欠測のない経路例。
- 下表の場中価格だけからH/Lを計算。前終値100をH/Lへ追加しない。
- 実装規約は[合格条件](精度の合格条件.md)。現物前日比は使わない。

| 場中の順序 | 判定 | 根拠 |
| --- | --- | --- |
| 100.7→100.3→100.6 | 上がる | 初回は上。反転0.4％、終点＋0.6％で、もみ合いに該当しない |
| 99.3→99.7→99.4 | 下がる | 初回は下。反転0.4％、終点−0.6％ |
| 100.7→100.1→100.6 | 上がってから下がる | 高値から0.6％反転。終点が前終値より上でも成立 |
| 99.3→99.9→99.4 | 下がってから上がる | 安値から0.6％反転。終点が前終値より下でも成立 |
| 100.6→99.6→100 | もみ合い | 場中幅１％・終点差０％。反転より優先 |
| 100.8→99.0→100.6 | 上がってから下がる | 複数往復でも最初の上方向到達と最初の反転で固定 |
| 100.49→99.51→100.1 | 主評価の対象外 | 前終値比±0.5％へ到達していない。回答自体は保存 |

- 0.5％到達・0.5％反転・幅１％・終点絶対0.5％は等号を含む。
- 同じ１分足の高安順序で判定が変わる場合は未確定。陽線・陰線だけで順序を仮定しない。
- 観測幅が１％以内でも、欠測区間で高安が広がった可能性は消えない。
- 対象内の無回答は不正解。観測不足による判定不明とは別に数える。
