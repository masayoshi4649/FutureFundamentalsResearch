# 同じデイ／ナイトの観測幅を比較する

- 当回の承認済み反応viewだけから、同じ場の直近最大６例を満了時計順で選ぶ。成績・方向・幅では選別しない。
- `local/本文遮断連続/同じ場の幅を比べる.py --snapshot 当回view --session 対象場 --out 新規出力`。元view・予測・点・採点を変更しない。
- 先物別にcase・P0・観測幅下限と、下限の最小／中央値／最大を表示する。未知を０にしない。
- すべて欠測を含む下限。中央値や最大も真の通常幅・予測区間・80％包含を表さない。独立標本数は不明。
- 本人は今回の中心幅・想定帯と実数で比較し、材料・現在地・現物開閉・市場条件の相違を記す。
- 直近の幅より小さい見積りなら、収縮を支持する根拠と、広幅になる反証を比較する。小さい合計材料点だけを収縮の根拠にしない。
- 比較は方向・点・帯・確率の自動生成ではなく、原案と対立案を同じ根拠で点検するため。過去の幅へ機械的に合わせない。
- 第22の既知入力を使った親確認と、未来・別締切・重複・未知・別場・古い大幅の選別拒否等10確認を実施。第22へ遡及配信しない。第23以降の未固定予測から使う。
