# 引け近傍候補の状態確認

- [初版の観測方法](前場引け近傍の補助観測.md)に加え、予測へ渡す価格は状態1（現値）・8（終値）・23（板寄せ約定）のいずれかを同一候補で観測した場合に限る。[APIの一次仕様](https://raw.githubusercontent.com/kabucom/kabusapi/master/reference/kabu_STATION_API.yaml)
- 初版の`available`は候補が一意という意味だった。状態−1だけの候補もあったため、未使用の第19場以降には別版２を使う。
- 状態−1は今回確認した一次仕様の定義一覧にない。価格値が入っていても利用可能とは認定せず、版２は価格を非表示にして時計・状態・理由だけ残す。
- 元の表示・出典を上書きしない。予測・反証担当へ許可するのは当回の版２とその説明だけ。
- 状態1や23の観測を、公式引けの独立確認へ格上げしない。受信時計・CSV限月の不足、P0非置換、+１秒の原時計保持は初版と同じ。
- 効果は未測定。結果を見た採用・不採用ではなく、全対象へ同じ状態条件を適用する。
