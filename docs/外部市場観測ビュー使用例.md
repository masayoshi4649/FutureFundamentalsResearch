# 外部市場観測ビューの使用例

`research_support.external_market_view.build_external_view` は、読み込み済みの応答から指定時計までの外部比較観測だけを作る純粋関数です。ファイルや通信へアクセスせず、元応答も変更しません。

```python
from research_support.external_market_view import InstrumentSpec, build_external_view

# 保存形式が {request: ..., response: ...} の場合、呼出側でresponseだけを渡す。
responses = {ticker: saved["response"] for ticker, saved in saved_by_ticker.items()}
specs = {
    "JPY=X": InstrumentSpec("米ドル円", "円／米ドル", "円安", "取得履歴の訂正履歴と初配信時計は未確認。"),
    "ES=F": InstrumentSpec("米株先物系列", "元応答の価格単位", "観測価格の上昇", "Yahoo連続系列であり過去限月を未確認。"),
    "NQ=F": InstrumentSpec("米株先物系列", "元応答の価格単位", "観測価格の上昇", "Yahoo連続系列であり過去限月を未確認。"),
    "CL=F": InstrumentSpec("原油先物系列", "元応答の価格単位", "観測価格の上昇", "Yahoo連続系列であり過去限月を未確認。"),
    "^TNX": InstrumentSpec("米国債利回り観測", "元応答の利回り表示単位", "利回り観測値の増加", "株価ではなく利回り観測。bp換算しない。"),
}
result = build_external_view(
    responses,
    as_of="2026-10-17T12:00:00+09:00",  # 架空の使用例。
    anchors={"比較開始": "2026-10-17T11:00:00+09:00", "比較終了": "2026-10-17T12:00:00+09:00"},
    instrument_specs=specs,
)
```

`Datetime` は足始端です。既定では5分足の終端から30分を経過した足だけを候補にし、足終端からアンカーまで60分を超えると「鮮度超過」として比較差・騰落率をnullにします。各観測にアンカー時計・採用足始端／終端・仮定上の表示可能時計・経過分数を表示します。アンカー時計そのものの正確な同時価格ではありません。全OHLCがnullの行は観測なし、部分nullや不正なOHLC・未知列はエラーです。穴を補完しません。同一足を両アンカーで採用した場合は「同一足」、別足で同じ終値なら「同値」と表示します。

全アンカー対について、アンカー間と採用足間の経過分数、元単位の単純差、相対変化率を返します。利回りの単純差にも明示単位を付け、bpへ換算しません。

後日収集の履歴であり、訂正履歴と初配信時計はありません。30分の遅延は開発仮定で、配信遅延の上限や厳密な当時受信の証明ではありません。収集時計と許可した出所metadata、全応答・ticker別の正規化JSONのSHA256を保存します。raw全行、未来の範囲・件数、日次高安は返しません。未来行の追加で変わり得る表示はダイジェストだけです。入力の検証違反は未来行も含めて拒否します。

合成入力だけの検査: `python -m unittest discover -s tests -p test_external_market_view.py`
