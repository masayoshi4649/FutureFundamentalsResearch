# 結果ニュースと先物反応を振り返る

- 第20場以降に適用する。予測固定→独立認定→結果開示の後で、同じ予測担当が結果ニュースも読む。予測・担当記録・過去の振り返りは上書きしない。
- 主要な予定指標は最大２件、窓内の主導材料と合わせて最大６記事を本人が見出しから選ぶ。別担当が場の終了を締切として主文を切り出し、未切出本文を本人へ表示しない。
- 記事公開・取得・更新・有効時計、原本・版・切出区間を照合する。予測時点の既知記事と、予測後に公表された結果記事を別保存する。独立認定の採否は変更しない。
- 予測時点に知っていた予想と、結果記事が伝える直前予想を区別する。実績・単位・予想差は出典付きで記し、未確認を推測補完しない。
- 実公表時計、予定時計、記事公開時計を分ける。実初報不明の記事を、公開時計から遡って公表前・公表後の原因にしない。
- 価格反応は同じ先物の確定した観測足で測る。P0比と発表直前観測値比の分母・実足時計を分け、予定窓と実観測窓、欠測を示す。欠測や未確定足を補間せず、取れない値は不明にする。
- 主要材料群は最大３件。材料名・検索キー・経路、予想と実績、反応、同時材料、成立・棄却条件を`market_reaction_updates`へ保存する。観測上の対応と単独因果を区別し、同じ場の２指数や転載を独立した確証へ数えない。
- 新しい根拠・本人の実読・SHA・時計の別検査を`review_evidence`として振り返りへ束縛し、次回の可知性ゲートへ通す。元の予測材料点を結果に合わせて変更しない。
- 短いMarkdownには主要な結果差・反応・修正だけを箇条書きにする。詳細はJSONへ保存し、追加材料の検索キーも次の事例検索へ引き継ぐ。
