# 過去反応を次の予測へ使う

- 当回の主導材料・比較目的を先に決める。的中した事例だけを選ばない。
- 既定の直近12場は索引。採用する事例は、元の考察の初動変更条件・反転棄却条件・幅と終点の反証まで読む。先頭200字を全文と扱わない。
- 共通する材料、P0での織込み、前セッションの状態、Day／Night、現物開場、相違点を本人が記録する。
- 同種セッションの観測幅下限と、今回の想定経路幅を実数で比較する。欠測を含む下限から真の通常幅・確率を作らない。
- 反転の有無（0.5％）、反転量、終点符号を分ける。過大な振幅を直して同じ分類を維持する案と、分類を変える案を同じ根拠基準で比較する。
- T／B0は既知期待・初報・同じ先物の共通窓・P0後窓の根拠から見直す。実績からの逆算や、同じ変化の複数材料群への全量帰属はしない。
- 観測と機序仮説を分ける。単発の反転や同じ材料の反復、同じ場の両先物を独立な確証として数えない。

## 古い同系事例の追加検索

1. 本人が当回の主導材料・検索語・比較目的を結果を見る前に指定する。
2. `snapshot_memory` の `story_keys`／`keywords`／`channels` で最大30場を検索する。満了・振り返り・根拠時計の既存ゲートを通す。
3. 既定12場との重複を除き、材料一致順位・満了時計によって最大6場を選ぶ。成績や反応方向で選ばない。
4. 別の当回用snapshotを本文遮断ビューにし、検索条件・候補数・順位・上限打切の有無・出力SHAを固定する。
5. 本人が必要な原文を実読し、採否と今回への適用条件を担当記録へ残す。

- 候補上限に達した場合は全履歴を網羅したと記さない。該当なしと未検索を区別する。
