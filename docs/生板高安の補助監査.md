# 生板の高安欄と欠測

- 開示済み第１〜17場の34先物回を探索点検。元価格・予測・採点は変更していない。
- 生板は高値・安値と各時計を持つ。[APIの一次仕様](https://raw.githubusercontent.com/kabucom/kabusapi/master/reference/kabu_STATION_API.yaml)はこれらの項目名を定義するが、今回の全経路収録を保証しない。
- ナイト18先物回は末尾応答の始値・高値・安値時計が対象場内。17回は１分足の観測高安と一致し、10/1NightのNK225は高値が10円上だった。
- デイ16先物回は始値時計が当該デイ開始より前。高安時計だけがデイ内でも、欄全体をデイだけの集計へ読み替えない。
- 先頭応答には前場の価格時計・前営業日の始値等も残る。ファイル名だけで全行を当該場の約定へ割り当てない。
- 末尾応答までの高安と公式引けまでの高安は別。未収録の引け前後や、欠測中の±0.5％到達順・反転有無を補完しない。
- 採点の確定度を上げる材料にするには、集計期間・更新順序・受信時計・終端収録を別に確認する。今回の照合だけで未確定を正解へ変更しない。
- 詳細：[比較付き監査](../local/本文遮断連続/生板高安の時計監査0017_比較付.json)。先頭・末尾の限定読取であり、全行監査や独立価格源との照合ではない。
- 別の全行探索では、同じ34先物回の当該生板全行と次ファイル先頭を合わせて4,507,847行確認した。CSV行のない1,663分のうち、有効な価格時計が残る候補は9/23DayのNK225・12:23、9/29NightのNK225・03:06の２分だった。価格経路の再構成や旧採点の変更はしていない。[不足分の探索](../local/本文遮断連続/生板による不足分の探索0017.json)
- この探索で未検出だった分も、無約定とは認定しない。価格時計の有無と受信・訂正・同時計内順序は別に確認する。
