# 検証で得た知見

- 状態：予測優位性は未確立。下記は実装制約と仮説の診断であり、80％達成済みの相場法則ではない。
- [先物の展開を読む別検証](../検証/00014_先物の展開を読む/README.md)：古い材料の水準と最新変化を分け、主導材料・寄付き・継続／反転を個別に判断する。9/22デイでは上値が観測されてもNKの「上がる」は外れた。説明の改善や初動の一致を、五分類の正解へ読み替えない。
- 同日のナイトでも参考採点は両先物不正解。既反映点・残余点が未識別のまま、日中終盤の弱さを13時間の下落継続へ延長する根拠が不足した。短期の押しと主導材料の失効を分け、前回の外れに合わせて方向を反転する規則へ一般化しない。
- 騰落は同じ先物の前セッション基準。ナイト急落後のデイ反発を、現物前日比で下落判定しない。[定義と回帰試験](研究設計.md)。
- 10/16は現物日経平均＋1.39％の反発記事に対し、対象のNK225先物は直前ナイト比−0.243％。この逆方向の事例も、先物の分母を固定して採点した。[当日の考察](../検証/00007_新方式の終了前固定/個別考察.md)。
- 悪材料とナイト下落を次デイの下落へ二重加点しない。ただし安値からの戻りだけでも次デイ反発を断定できない。[実測状態の検証](../検証/00005_実測した既反応と分類/README.md)。
- 信頼度・新規性・未織込度を掛けた４材料点は変動が小さく、初期回帰では定数項が支配した。標準化だけでも精度は改善しなかった。[循環４〜６](../検証/00003_学習期間の延長/README.md)。
- 生の材料点を実測価格へ追加すると、今回の同一18時点では5/18・8/18から4/18・5/18へ悪化。主観的な積を外すだけで予測内容が正しくなるわけではない。[比較結果](../検証/00005_実測した既反応と分類/README.md)。
- 全文と実測状態へ戻し、各回の担当を分けて過去結果を渡しても8/18・7/18で不合格。自由な説明の追加も、そのまま方向精度の向上にはならなかった。[循環10](../検証/00006_全文と実測反応による直接判断/総括.md)。
- 記事中の米株・為替の実数も、今回の分類法では方向の優位性を示さなかった。市場総括と、発表時の実績・予想・改訂差分は分けて扱う。[循環９の診断](../検証/00005_実測した既反応と分類/09_記事中の市場数値と実測先物/診断と修正.md)。
- Fisco中心の取得範囲では、国内指標の実績・市場予想を含む別ソースのレポートを取り逃がしていた。本文に後日の関連記事も混在するため、取得範囲と主文の時点整合を両方直す。[ニュース源の追加点検](../検証/00008_ニュース源の追加点検/README.md)。
- 記事の前日比と前日引けが不整合な例がある。数値の見かけの精密さを信頼性と同一視せず、原数値を残し不整合を特徴から外す。[観測監査](価格とニュースの観測監査.md)。
- 末尾窓に欠測がある場合、開始・終了・観測足数を記録する。今回の全18時点は完全な60分窓ではなかった。[独立監査](../検証/00005_実測した既反応と分類/監査結果.md)。
- 条件別に上昇・下落が偏る少数例はあるが、後付けの頻度を予測確率へ昇格しない。[各先物30件の反応台帳](../検証/00005_実測した既反応と分類/既反応と次場の対応.md)。
- 過去の名目80％経験範囲でも、次場終点の包含はNK225が8/15、TOPIXが9/15。範囲発行は15/18回であり、将来の80％包含を確立していない。[レンジ照合](../検証/00005_実測した既反応と分類/経験レンジの照合.md)。
- 同じ18時点を何度再生しても独立標本は増えない。予測固定後の未使用期間で、全予定回の発行率と一致率を確認する。[合格条件](精度の合格条件.md)。
- 五分類は終点の符号だけでは採点できない。もみ合い優先、最初の0.5％到達と反転を時系列で確認する。欠測を補間して高安順を作らない。[算定例](五分類の算定例.md)。
- 未知の臨時材料による終了と、予定済み発表のサプライズを分ける。独立点検で公表時計まで採用できた材料は０。記事時計を架空の実公表時計に置き換えない。[認定概要](../検証/00012_臨時材料前の五分類/材料認定の概要.md)。
- 後日の保留で過去教師を早く除くことも情報混入になる。根拠全記事の収録版の取得時計を過ぎた次の締切から教師を訂正し、その時点別履歴を保存する。[反復計画](../検証/00012_臨時材料前の五分類/実験計画.md)。
