# 外部市場の同期比較

- 目的：為替・米株先物・原油等の観測窓をそろえ、古い記事の前日比と先物P0以後の変化を混同しない。
- ニュース本文は指定ニュース取得ツール、国内の採点価格は既存リポジトリを引き続き使用する。
- 追加の市場データ取得ツールでは全providerを比較した。国内日足・現在板・日足履歴・予測市場価格では必要な海外の過去分足がそろわず、履歴分足を提供する `yfinance.history` を開発用の補助観測として選んだ。
- 対象：USDJPY `JPY=X`、米株先物 `NQ=F` / `ES=F`、WTI先物 `CL=F`、米10年利回り指標 `^TNX`。為替上昇は円安。利回りの相対変化率と金利差のbpを区別する。
- Yahooの先物系列は過去の各限月を確認できていない。限月をまたぐ変化を同一限月の反応と断定しない。国内先物と同一商品として接続しない。
- 原応答は後日の収集版。実際の初配信時計・過去の訂正履歴はない。厳密な当時の受信記録や独立した将来運用の成績には使わない。
- ５分足の始端だけで確定扱いせず、終端に固定30分の表示余裕を加えて締切と照合する。30分は開発上の保守仮定であり、当時の配信遅延上限が証明された値ではない。
- アンカー以前の最後の足だけを選び、実際の足時計と古さを表示する。60分を超える古い観測や観測なしの区間は比較値を未算出にし、無変化へ置換しない。
- P0・情報締切等のアンカーは事前に固定し、比較には実際に選んだ足の終値を使う。後日の最高値・最安値や締切後の足は表示しない。
- 外部観測を国内先物のD・B0・材料点や原因へ自動換算しない。共通ショックによる円・金利・株価の同時変化を三重に加点しない。
- 新00016の最初７場へ遡及入力しない。追加後の場を記録し、前後の成績は開発手順が変わったものとして比較する。

銘柄確認：[Nasdaq先物](https://finance.yahoo.com/quote/NQ%3DF/)、[WTI先物](https://finance.yahoo.com/quote/CL%3DF/)、[米10年指標](https://finance.yahoo.com/quote/%5ETNX/)。現在ページの相場本文・関連記事は過去の予測担当へ渡さない。
