# P0と同じ終端の外部足を照合する

- 既存の`P0_先物`アンカーは、固定30分遅延を仮定して「P0当時までに利用可能な外部足」を選ぶ。その足自体の終端はP0より古い。
- 別表示では、予測締切までに利用可能な外部足の中から、国内P0と同じ終端の足を探す。P0当時の受信記録や、当時保存済みの判断とは扱わない。
- P0終端＋30分を確認時計とし、これが予測締切以下の場合だけ既存の純観測処理で照合する。将来の足や締切後に利用可能な足は使わない。
- 外部の実足終端がP0終端と一致しない場合は計算しない。閉場・非整列の時計・鮮度超過を補完しない。
- 夜の16:00では、直前デイ終端から30分がまだ経過していないことが多く、同終端比較は利用不能になる。既存の古いアンカー値で代用しない。
- 一致時の差は同じ外部系列内の変化。国内先物のD・材料点・寄付きギャップ・因果効果へ自動換算しない。
- 同じ足終端でも個々の約定時計は同時とは限らず、後日履歴・未確認の限月・訂正履歴・仮定遅延という限界は残る。
- 新00016は第18場以降の別補助。既存の観測、予測、採点は差し替えない。
