# 精度の合格条件

- 2026年10月16日のユーザー指定：方向一致80％以上を目標とする。
- NK225先物とTOPIX先物を別々に判定。日中・夜間の内訳も示す。
- 同じ先物の前セッション基準から対象終点まで。実績横ばいの境界は事前固定。
- 一致数／方向発行数、方向発行数／全予定回数、保留数を必ず併記。
- 外れた回を未知材料として除外せず、保留増加による見かけの改善も合格にしない。
- 同じ発行回の単純基準との差を確認する。
- 規則・対象期間・発行条件を先に固定し、未使用期間で確認する。
- 結果を見た期間での再調整は開発実験。80％に到達しても独立検証の合格にしない。
- 価格レンジの80％包含と方向一致80％を混同しない。
- 反復回数、少数標本の偶然、同日・同材料の依存を隠さない。
- 80％の達成を保証せず、未達の方式は不合格として保存する。
