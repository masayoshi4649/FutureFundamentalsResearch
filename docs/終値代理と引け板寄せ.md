# 終値代理と引け板寄せ

- 日中のザラバは15:40まで、引け板寄せは15:45。夜間のザラバは05:55まで、引け板寄せは06:00。[JPXの立会時間](https://www.jpx.co.jp/derivatives/rules/trading-hours/index.html)
- 日中の15:40終了・15:45板寄せ、夜間17:00開始は、2023年９月22日公表・2024年11月５日施行の規則改正に記載。[改正概要](https://www.jpx.co.jp/rules-participants/rules/revise/jr4eth0000002tew-att/gaiyo.pdf)
- 夜間05:55までのザラバも新旧対照表に記載。06:00までの延長は2021年９月21日に実施済み。[新旧対照表](https://www.jpx.co.jp/rules-participants/rules/revise/jr4eth0000002tew-att/shinkyu.pdf)、[稼働案内](https://www.jpx.co.jp/corporate/news/news-releases/0060/20210921-01.html)
- 15:40・05:55付近の最終観測値と、引け板寄せ価格は分ける。前者を公式終値と断定しない。
- 引け準備の時間を、連続ザラバの収集欠損と同一視しない。制度上の無約定時間と、通常取引中の不足を説明上区別する。
- 未収録の引け値・高安・反転順序は作れない。未知のDを０へ補完しない。
- 固定済み評価の`missing_rows`は期待足との差。今回の制度説明追加を理由に、旧P0・予測・ラベル・分母・品質件数を変えない。
- 新しい制度資料は公表日・原本SHA・使用範囲を固定する。公表時分不明、現在原本と当時保存版との一致未検証という限界も残す。
