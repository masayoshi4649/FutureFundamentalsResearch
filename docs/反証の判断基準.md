# 反証と最終判断

- 反証は最大3点。該当なしの0点も認め、件数を満たすために重大な問題を作らない。
- 指摘は「算術・規約違反」「事実の誤読」「予測に反する積極的証拠」「未識別・不確実性」に分ける。根拠資料と該当箇所を記す。
- 未識別や不確実性だけでは、原案が反証されたことにも、対立案が支持されたことにもならない。
- 原案と対立案の寄付き・途中経路・終点について、支持条件と棄却条件を同じ形式・証拠基準で比べる。
- 反転の有無（0.5％）、反転量、終点符号を個別に点検する。量を修正して同じ分類を維持する案も比較する。
- 新しい反発・反落材料が見当たらないことだけで、途中の0.5％反転がないとしない。
- 同じ材料・価格窓・伝達経路を独立な複数の反証として数えない。
- 最終予測担当が各指摘を採用・一部採用・棄却し、理由と変更内容を記録する。レビュー担当への同意を必須にしない。
- 不確実性を残しても、当回の五択回答は本人が決める。対象内の無回答を免責にしない。
- 草稿と正式回答は結果前に固定する。同じ結果・材料認定で対応比較し、未発行草稿を正式成績へ付け替えない。
- 新00016では第16場以降の静的手順。既存予測と既存のレビュー指示を修正しない。手順変更の時点を残し、反証の因果効果や精度改善を未測定のまま断定しない。
