# 米半導体の市場反応を比較する

- `^SOX`（PHLX半導体指数）と`MU`（Micron）のYahoo5分足を、関連材料に対する海外反応の参考にする。国内先物のP0・採点価格・材料点を置き換えない。
- Micronは時間外を含む提供足。指数と個別株の単位・取引時間・流動性を区別し、時間外価格を日本株の約定可能価格や同時刻の全面的な買いとしない。
- 米国現物の終了後を含む文脈用なので鮮度上限は24時間。既存の為替・先物の60分と用途が異なる。実足時計と経過分を必ず読み、古い終値を直近の新規取引と記さない。
- 足終端＋固定30分が各アンカー以前の観測だけを使う。上限超過・欠測は補完しない。週末等で24時間を超えれば表示可能な比較は不明になる。
- 後日取得履歴であり、初配信・訂正履歴を持たない。30分は開発仮定で、当時の受信や正確な同時価格を証明しない。
- 同じ記事でも、旧AI期待と新しい企業決算・見通しを経済事象別に分ける。総影響とP0までの既反映を別に判断し、旧負担の水準だけを次場の追加売りへ延長しない。
- 企業の価格反応と、同時に動く金利・為替・Nasdaqを同じ原因の独立した複数票にしない。Micronや指数の変化全量を国内対象先物へ帰属しない。
- 寄付き、継続・反転、終点・幅のどの仮説を支持するかを本人が記す。％から主観pt・確率を自動生成しない。
