# 経験を判断基準へ取り込み、別期間で検証する

## 今回の変更の位置付け

- この改訂は2026年10月19日の朝予測・12:15までの観測と、ユーザーの単一終値指定を反映する。
- 観測事実：P0比の位置だけでは直近の回復を表せない。材料Rが未識別でも負のTを重く語り、当初の主観終値と価格反応が結び付いていなかった。
- 手順上の修正：P0比と直近反応を併記、残余不明の明示、相対差と市場全体の広がりを区別、単一終値の推定根拠、反証成立と実際の改訂時計を分離する。
- **未実証**：この変更で正答率・終値誤差が改善すること。今回の価格水準、回復幅、反証水準を普遍的なルールにしない。
- 元事例を使う場合だけ[朝の振り返り](../../../../予測/20261019_デイ_昼更新1215/朝の見立ての振り返り.md)を読む。古い締切のブラインド担当へ、未来の元事例や数字を渡さない。
- 本改訂で既知の期間を再生する場合は開発検証。担当だけを新しくしても、規則の設計に使った期間が未使用期間になるわけではない。

## 反応事例の記録

[市場反応の更新](../../../../docs/市場反応の更新.md)の既存台帳に従い、新たな仕組みと互換性を装った別形式を勝手に混在させない。追加観測は別補足へ保存して原caseとSHAで結ぶ。

| 区分 | 保存するもの |
| --- | --- |
| 事例の資格 | case ID、商品・限月・デイ／ナイト、予測発行・評価満了・評価記録時刻 |
| 材料 | story key、初報・実質変更、事前予想・実績・改訂、公開／利用可能時計 |
| 予測時点の状態 | P0比、直前場変動、寄付き・直近方向・極値からの回復、広がり、欠測 |
| 既反映 | B0/Dの根拠、未識別、価格反応という代理特徴量か材料の因果推定か |
| その後 | 事前指定窓の先行方向・反転・高安幅・単一終値誤差、他材料の重複 |
| 判断 | 観測事実、解釈仮説、次回変更、反例、採用／保留／不採用 |

- 原因不明と、データ取得不足と、当時確認できた事実の見落としを分ける。
- 後発記事が値動きを説明していても、記事公表前の値動きを記事の効果にしない。
- 材料の良否→価格の方向を固定せず、同じ材料でも異なった反応を保存する。

## 比較検証

1. 修正する判断を特定する。例：「同先物P0比だけでなく直近反応を加える」。成立条件と対立仮説を先に固定する。
2. 母集団・情報締切・学習可能な満了事例・開発期間・未使用期間を固定する。過去の結果を見て対象回を選ばない。
3. 比較元と変更版を、同じ情報締切・同じ採点・同じ分母で予測固定する。初回は価格反応追加、次に広がり追加等、変更の寄与を比較できる単位にする。
4. 先物別・デイ／ナイト別に五分類、単一終値の絶対誤差・P0比誤差、レンジ包含と幅、無回答・未確定を比較する。
5. 反証後の改訂の速さは別指標。早く見直せたことを開始前の的中率向上へ加算しない。
6. 改善・不変・悪化を保存し、不採用も残す。未使用期間での確認がなければ「候補」として保持する。

- 予測時点より後の評価記録・後日の材料認定を学習に混ぜない。同じ場の再試行や期間の重なる長期予測を独立標本として水増ししない。
- 過去類似例の検索条件・上限は結果を見る前に固定し、当たり例だけを拾わない。[過去反応の再利用](../../../../docs/過去反応の再利用.md)の原文条件と反例を読む。
- 現行の五分類80％、終値推定の精度、価格補助スクリプトの正しさは別の評価。スキルの文章やテストが整っただけで予測方式の完成にしない。
