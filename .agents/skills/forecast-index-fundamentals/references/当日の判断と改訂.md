# 当日の判断と場中改訂

## 最初にそろえる観測

| 項目 | 記録する内容 | 混同しないもの |
| --- | --- | --- |
| 基準 | 商品・限月・P0・実価格時計・代理理由 | 現物前日比、日通し板の前日比 |
| 現在地 | 現在値とP0比、寄付き・高安、観測終端 | 当日の現在地と、これからの予測 |
| 直近反応 | 固定した5／15／30分窓の価格変化・極値からの回復、欠測 | その窓内の変動と真の材料別寄与 |
| 材料 | 初報・実質変更・予想との差・既報、利用可能時刻 | 朝配信された昨夜の解説と新しい悪化 |
| 広がり | 時刻の合う業種別寄与・騰落銘柄数・出来高 | ２指数だけの相対差と市場全体の広がり |
| 外部 | 為替・金利・原油・海外先物の値と比較時計 | 最新取得時刻と価格自体の古さ |

- 必要な追加情報から優先して取る。取得できない観測は未取得のまま記し、数値や因果を補完しない。
- 当日足は時刻と確定状態を確認する。収集snapshot時計が受信時計を先行する場合、その時計だけで足を確定扱いせず、実際に終了した足までに限定する。
- デイ単独の出来高・VWAPと、ナイトを含む日通しの値を分ける。板だけで新規買いと買戻しを断定しない。
- 外部価格が不整合なら不採用理由を保存し、ニュースの古い値を現在の実測値として補わない。
- 制度や市場営業日の確認が必要なら、[旧詳細の価格確認](過去検証と既存実装.md)と、そこから参照する原資料を読む。

## 材料から予想へのつなぎ方

- 各先物について、少なくとも「材料に沿う動きの継続」と「既反映・吸収による逆方向」の根拠を比べる。対立案を後から両方正解にはしない。
- 例：悪材料後のP0比がプラスで、直近の押し目からも回復していれば、追加下落を主張するには新たな悪化・上値失敗・売りの広がり等の根拠が要る。反発だけを買いの普遍則にもしない。
- P0比横ばいと直近横ばいは別。方向判断では基準からの位置と直近の変化を併記する。
- Tは材料の総作用、Rは今後の残余。R未識別なら、Tの大小から今後の方向を直接決めず、観測反応・比較事例・対立仮説に基づく裁量判断だと明記する。
- 材料ごとの因果分解を観測値のように扱わない。過去事例でも正確な織込み率は直接分からないため、価格反応を代理特徴量として使う場合はそう記す。
- 不確実だから常に保留へ逃げない。根拠に基づき主回答を選び、未校正・不足を明記する。出せない場合も対象内の無回答として保存する。

## 単一終値を決める

- 終値は一つの価格。百分率はその価格から `100 × (終値予想/P0 − 1)` で導出する。場中は現在値比も別に示す。
- 推定の根拠は、利用可能な条件別の過去反応、現在値から残り時間の展開、支持・抵抗や予定イベントのどれかを具体化する。
- 検証済みモデルがあれば版・学習期限・標本数を記録する。なければ「裁量推定・未校正」と記し、材料点から価格を換算したように装わない。
- 場中高安レンジは終値予想と別。全日レンジなら既観測高安を含み、残時間レンジなら対象開始時刻を明示する。
- 五分類・主シナリオの価格経路・終値・高安幅の整合を確認する。既に成立した全日パターンを、これからの方向の代わりにしない。
- 校正済みの信頼区間や80％の確率として表示できるのは、その検証がある場合だけ。

## 反証を事前固定する

- 価格条件には対象先物、価格種別、閾値、比較（超／以上・未満／以下）、足幅、連続数、必要な併用条件を書く。
- 材料条件には対象材料、失効・悪化・改善を判断する観測を書く。価格だけで未予定の臨時材料を認定しない。
- 成立しても主回答の事後差替えはしない。維持／修正／不明を判断し、修正は前版と根拠を付けて新規発行する。
- 予定の発表後に見直す時刻と、価格条件による見直しを分ける。自動監視未設定なら、依頼時に確認した記録にする。

補助スクリプトのルールファイルは次のJSON配列。値は例であり、各回に根拠付きで決める。

```json
[
  {"id":"NK上抜け確認","operator":"above","threshold":64750,"consecutive_bars":2,"bar_minutes":5}
]
```

```powershell
python .agents/skills/forecast-index-fundamentals/scripts/inspect_session.py --input local/今回/NK225.json --as-of 2026-10-19T12:15:00+09:00 --session-start 2026-10-19T08:45:00+09:00 --p0 63590 --reference-price 64280 --rules local/今回/事前反証.json --output local/今回/NK225価格確認.json
```

- 入力は `time,open,high,low,close,closed` の1分足CSV、または `{"data":[足...],"snapshot":...}` のAPI保存JSON。数量の完全性は `volume_complete`／`volumeComplete` で補足する。
- `--as-of` と `--session-start` はタイムゾーン付き。足開始から１分経過・closed真の足だけを採用する。P0・reference-priceは正数。
- aboveは厳密な「超」、belowは「未満」。session-startを起点に完全な５本を集約する。２先物の同時条件や材料条件はこのスクリプト単独では判定しない。
- 同じ入力とルールのSHA・事前保存時計を予測記録へ結ぶ。結果を見て閾値を作ったものは事前反証ではない。
- 出力は既存ファイルを上書きしない。価格の欠測は示すが、通信停止か無約定かは別証拠が必要。

## 発行するもの

- 新規フォルダ：短い `予測.md`、単一終値を含む構造化予測、参照原本のSHA、観測時刻・締切・発行時刻。
- 改訂時は、前版ID、旧終値→新終値、変わった材料と反応、反証成立時刻・確認時刻を追加する。
- 初回予測・場中改訂・満了後の振り返りは別記録。改訂値で当初の精度を良く見せない。
