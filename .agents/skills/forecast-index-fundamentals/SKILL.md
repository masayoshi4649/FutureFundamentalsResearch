# NK225・TOPIX先物の見通しを作り、反応から更新する

日本語（UTF-8）で、このリポジトリのルートを作業場所にする。予測と振り返りは短いMarkdown・箇条書きで残す。利用者が求めたセッション・期間だけを扱う。

## 依頼に合うモード

| 依頼 | 実行と情報の扱い | 評価 |
| --- | --- | --- |
| 07:45／16:00の開始前予測 | 締切から5分以内かつ開始前に発行。間に合わなければ情報を取り直すか、実際の時点の場中予測として別発行 | 開始前予測の固定分母 |
| 今の情報で予想・昼に見直し | 現在時計を確認して最新本文・確定価格を直接取得。過去検証用の本文遮断・別準備役は不要 | 残時間方向・単一終値の誤差・残時間レンジ。開始前成績へ混ぜない |
| 過去からブラインド検証 | 未来本文・結果を先に読ませない。[過去検証と既存実装](references/過去検証と既存実装.md)を読む | 予測固定→満了→独立材料認定→開示→振り返り→次回 |
| 何故外れたか・経験を更新 | 当初入力と予測を固定して、見落とし・後発材料・未識別を区別。[経験の再検証](references/経験の再検証.md)を読む | 仮説追加と未使用期間での改善実証を区別 |

- 場中でも情報締切・注釈完了・実際の発行時刻を分ける。収集から時間が空いたら価格・新着材料を再確認し、新しい締切で発行する。
- 「現在情報・マスク不要」は現在モードへ適用する。過去の結果を使った再作成をブラインド成績にしない。
- スキル更新元の事例を同じ版で再予測した結果は開発再生。未知期間での精度改善とは呼ばない。

## 固定する基準

- 07:45は直前ナイト、16:00は当日デイの**同じ先物・同じ限月の終値P0**。現物前日比、CME大阪日中比、日通し板のPreviousCloseを無条件にP0へ使わない。
- 元CSVに公式終値がなければ、終了予定までの最終1分足を10分以内に限って代理にし、実観測時計を示す。公式終値・引け板寄せを作らない。
- 場中のP0は維持し、現在値からの残時間方向を別記する。観測済みの上昇・反転を新予測の的中へ加算しない。
- 原価格は `../FutureAlgorithmResearch` の `candle_1min`・`candle_5min`・`book` を読取専用で使う。欠測、未確定、受信時計・価格時計・限月未確認を残す。
- 当日CSVがなければ親リポジトリのAGENTSに記載された収録用読取APIを確認する。原本と取得時計は当リポジトリの新しい `local/` 配下へ保存する。
- ニュース源は[ニュース取得ツール](plugin://dev-6a663c9c11fc8191948f5f21250d8144@created-by-me-remote)。実在ツール・引数を確認し、記事ID・版・公開／取得時計・原本・採用本文を保存する。指定源に結果がなければ一次公表で補完し、取得不足と補完元を明示する。
- 伝達経路の学術的根拠が必要なら `S:/GitHub/masayoshi4649/MarketSkills/.agents/skills` を参照する。既存の固定点数を本対象の実証係数として移植しない。
- 既存予測・採点・入力を上書きしない。改訂は前版IDと新旧差を付けた別発行。旧三分類CLIを現行五分類の発行器として使わない。

## 予想を作る

予測・改訂では[当日の判断と改訂](references/当日の判断と改訂.md)を読む。点の意味は[材料の織込み点](../../../docs/材料の織込み点.md)、展開判断は[先物の展開予想](../../../docs/先物の展開予想.md)に従う。

1. **現在地**：P0比、直近の方向、寄付き後高安、安値／高値からの戻り、時間帯、欠測を分ける。P0比横ばいでも直近は上昇し得る。
2. **材料の更新**：初報・実質変更・既報解説を区別する。予定指標は市場予想・実績・改訂を分け、未発表結果を事実にしない。
3. **反応の比較**：材料に沿う継続と、吸収後の反発／反落を比較する。悪材料でも下がらない観測を落とさず、それだけで消化完了とも断定しない。
4. **先物別の波及**：２指数の相対差、業種寄与、騰落銘柄数、出来高等を区別する。業種・騰落数未取得なら市場全体への広がりを断定しない。
5. **点と過去例**：材料群ごとにT・B0・D・B・Q・Rを根拠付きで記す。R未識別ならTを追加売買圧力の代わりにしない。予測時点までに利用可能な満了済み事例と反例を比較する。
6. **主回答**：対立仮説を比較して主回答を一つ固定し、先物ごとに単一終値と場中レンジを示す。推定方法・根拠を記し、裁量値を校正済み推定値と呼ばない。
7. **反証**：価格水準・確定足条件・必要な材料変化を発行前に固定する。確認できない条件は未確認とし、次回見るものを書く。
8. **保存**：[予測テンプレート](assets/予測テンプレート.md)を必要範囲で使う。数値・参照入力・時計・規則版をJSON、説明を短いMarkdownで新しいフォルダへ保存する。

ptは主観注釈であり、百分率・確率・真の織込み率ではない。未知はnullのまま、B＝B0＋D、Q＝T−B0、R＝T−B0−Dを計算する。ニュースを使わない頻度代用をニュース予測として出さない。

## 価格反応と反証の補助

[価格確認スクリプト](scripts/inspect_session.py)は保存済みCSV／収録API JSONから、確定足・P0比・直近5／15／30分の反応・欠測・事前指定の反証を確認する。ネットワーク取得、ニュース判断、予測、五分類採点、自動監視は行わない。

```powershell
python .agents/skills/forecast-index-fundamentals/scripts/inspect_session.py --input local/今回/NK225.json --as-of 2026-10-19T12:15:00+09:00 --session-start 2026-10-19T08:45:00+09:00 --p0 63590 --output local/今回/NK225価格確認.json
```

- 日時・P0は当回の確認値に置き換える。入力と任意の `--rules` は[当日の判断と改訂](references/当日の判断と改訂.md)を参照する。
- 完全な５分足が揃わない窓を連続成立へ使わない。複数先物や材料を組み合わせた反証は、各観測と時計を照合して判断する。
- ルール成立・実際の確認・新しい発行の時計を別に保存する。後から成立を発見しても、当時自動更新したと記さない。
- 07:45／16:00の自動起動・継続監視・外部通知は、このスキルの作成だけでは設定されない。依頼されていない外部発信・注文を追加しない。

## 採点と経験の更新

- [五分類の固定規約](../../../docs/精度の合格条件.md)：場中にP0比±0.5％へ到達した回が対象。無回答は不正解。
- 回答は上がる／下がる／上がってから下がる／下がってから上がる／もみ合い。高安差がP0比1％以内かつ終点P0差が絶対0.5％以内なら、もみ合いを優先する。
- 反転はP0比0.5％の先行変動と、極値からP0比0.5％の逆行。終値でP0を越える必要はない。最初の到達方向を使い、足内順序・欠測を補完しない。
- 予定を知り得なかった大きな臨時材料だけ、独立認定した公表前までを主評価にする。予定指標の予想外の結果では打ち切らない。旧全場成績と全予定件数も残す。
- 満了前は途中診断。終了後に[振り返りテンプレート](assets/振り返りテンプレート.md)で、終値誤差・経路・理由を別評価する。
- [経験の再検証](references/経験の再検証.md)に従い、観測事実→改善仮説→変更規則→予測固定→未使用期間での比較→採否へ進める。一例の反省を普遍的な売買則や80％実証へ読み替えない。
- 過去検証では９月21日以降の実在デイ・ナイトを先に全件列挙し、不足・未実行も残す。既存の18締切や39場を将来の母集団へ固定流用しない。

## 長期見通しを求められた場合

１週間・１か月・３か月は材料別・NK225／TOPIX別の寄与、残存・失効・新材料を中心に追う。単一終点推定値を出す場合も方法と校正状態を明記し、日次係数や値幅を機械的に外挿しない。標本不足なら未算出。期限とロールは[研究設計](../../../docs/研究設計.md)で確認する。

## 呼出し例

- 「今の情報で今日のデイを予想して。終値は一つの値で」
- 「朝の予想を、現在の材料と反証条件で見直して」
- 「材料の既反映と価格反応を使う改善案を、未使用期間で比較して」

スキル整備・補助のテスト成功と、予測精度80％の達成は別である。未実証の状態をそのまま報告する。
